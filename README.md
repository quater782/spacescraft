# SPACECRAFT // 星航双子

一款无需联网、可单人或本地双人游玩的 WebGL 3D 合作射击游戏。

## 运行

可以直接双击 `index.html` 运行。也可以在项目目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

桌面调试：

```bash
npm install
npm start
```

## 操作

- 单人模式：P1 使用 `WASD` 移动，P2 由 AI 僚机接管
- 本地双人：P1 使用 `WASD`，P2 使用方向键
- 双手柄：左摇杆移动
- `Esc` 暂停，`M` 静音，`Enter` 开始/重开

射击、能量技能和近距离救援均为自动触发，玩家只需控制移动。

每章 Boss 后会进入一次只用方向键操作的“三选一”构筑：左右选择、上下确认。15 项局内升级覆盖自动武器、机动与双子系统三条路线，可叠层形成穿透齐射、自动僚机、连锁爆破、循环护盾和拾取牵引等组合；航行种子会显示在构筑页与结算页，可用于复现同一局候选与战斗随机序列。

升级之间还存在 7 种“双子遗物协议”。第一次构筑选中组件后，下一次三选一会至少出现一件可完成协议的配套候选；组合后自动产生高速侧翼齐射、屏障穿透、追踪蜂群、强化电弧、护盾新星、拾取晶弹或共振增幅等跨系统效果。协议选择与触发仍不需要战斗按键，并以矢量徽记、3D 轨道遗物、专属音效和任务报告清楚反馈。

同一枚航行种子也会生成一条三段生态航线。三章分别从 9 种生态中抽取场景；每个生态都有独立的动态积木微缩世界，近景航标、中景生态与远景地标持续向镜头推进，并改变光色、敌军偏好和自适应 8-bit 配乐。玩家三机体采用细长尖鼻、低矮机身、连续薄翼与航空尾翼构成现代战斗机剪影；敌军则由月牙、刺矛、甲壳、星镰、魟翼、双颚和母巢七个异形船体，以及推进轨迹、弹幕武器、防御核心、智能芯片与异常载荷六个维度组装，共有 7,168 种完整构筑。模块不是贴在表面的装饰，而会重塑尾部触须、武器颚、核心甲壳、眼阵和发光载荷脉络，并与实际航迹、瞄准、规避、屏障和 Debuff 规则对应。

四类战场拾取也会自动上线临时模块化 Buff：武库积木提高自动火力，纳米花簇加速并持续维修，神盾晶格拦截近身敌弹，通量磁环强化能量、牵引与光链。它们全部使用方块挂件、体素轨道、独立拾取音色和高清 HUD 反馈；终章敌人的霜冻、扰频与裂解载荷则用相同的建模语言预告减速、降射速或能量抑制。

每章开场还会出现三座实体 3D 星门。两架战机只需移动到同一航道即可自动锁定；七种航线协议会在支援、火力和高风险方案之间提供明确取舍，并实际改变即时奖励、敌军模块偏好、耐久、增援、弹速、得分倍率与本章音乐。单人模式的 AI 僚机会主动跟随 P1，超时则按当前航道自动跃迁，不增加任何战斗按键。

固定刷怪已经升级为种子化的动态遭遇导演：每章插入两次目标，从双子信标同步、星骸回收、移动信使护航、体素陨星生存与裂隙核心攻坚中组合。目标位置、类型和变体可复现，成功会给予双机共享奖励，错失也不会卡住航行；所有交互仍通过移动、接近、躲避或让自动火力对准目标完成。

首次出航会显示三步教学。设置页支持简体中文/英文即时切换、独立音乐/音效音量、三档 3D 渲染质量、屏幕震动、闪光强度和高对比敌方弹幕；选择与生涯统计会自动保存在本机。语言切换覆盖战斗 HUD 与当前任务结算，无需重启游戏。

主菜单的“双子机库”提供三种拥有独立 3D 几何与战斗参数的机体，以及四枚偏向能量、防御、救援或协作的核心模组。完成航行会获得星尘，用于永久解锁机体和模组；旧版本存档会自动迁移。

机库中的“恒星天赋网格”进一步提供 9 个跨航行永久节点。矢量机动、自动武装与双子共振各有三层依赖链，分别强化移动/碰撞容错、自动火力/超新星循环，以及光链/救援/共享护盾；星尘购买、前置状态和实际战斗属性会写入 v5 本地存档，旧存档无损补齐空网格。

战斗中的“双机共振”现在还会自动积蓄星链能量。保持编队、击破敌机、拾取资源、完成动态遭遇、自动救援和推进 Boss 阶段都能充能；满槽后自动进入“星链狂潮”，短时间强化全部自动火力、扩大拾取牵引，并把双机光链变成可熔解敌弹的移动防线。狂潮击破会延长持续时间并形成结算链，玩家仍然只需要控制方向。

机库还可签署巡航、风暴或过载三种航线合约。高难合约会同时改变敌军耐久、弹速、增援节奏、我方性能和结算倍率；八枚本地星航勋章记录关键里程碑，并使用稳定 ID 为后续 Steam 成就映射做准备。

## 技术说明

- Three.js WebGL2 透视相机、按色缓存的 `InstancedMesh` 积木体素、三阶 `MeshToonMaterial`、独立实体/自发光/轻辉光深度层与动态点光源
- 480×270 透明 HUD，3D 场景根据屏幕像素密度动态渲染
- Web Audio API 实时合成多轨 8-bit 配乐与音效
- 固定时间步游戏循环，避免不同刷新率改变游戏速度
- 玩家、敌军、Boss、分段拖尾弹幕、拾取物、星门与九套动态 3D 微缩世界统一使用 `BoxGeometry` 组合；玩家航空战机构造器与敌军异形器官构造器完全分离，功能模块改写外轮廓，不以手写面片或表面微方块堆砌造型
- 单人 AI 会预判弹道、保持共振队形、集火目标并优先救援
- 三章各有三种编队事件和一场精英战；Boss 拥有三阶段招式、护盾转场与镜头演出
- 星尘局外经济、三种可选机体、四枚核心模组和本地解锁存档
- 三档数据驱动航线合约与八枚本地星航勋章
- 统一中英双语文案目录、v5 天赋/语言存档迁移与自动缺失键检查
- 独立局内玩法随机源、15 项可叠层升级、7 种两件套遗物协议、配套候选注入与自动构筑测试
- 9 种确定性星域生态、7 个有机船体家族、六维 7,168 种模块化敌军构筑、程序化 3D 地标与生态自适应音乐
- 4 种自动 Buff、3 种敌方异常载荷、体素挂件/弹体/状态碎片与动态 8-bit 信号
- 每章三座可驾驶进入的 3D 星门、7 种风险/奖励协议、单人 AI 汇合与航线自适应音乐
- 五类模块化动态遭遇、每局六个种子目标、体素场景实体、共享奖励与自动失败回退
- 9 节点恒星天赋网格、三条前置依赖链、永久战斗效果与星尘长期成长
- 全自动星链狂潮、六类事件充能、击破延时、防弹幕光链、3D 轨道能量环与动态 8-bit 编曲
- 本地生涯记录包含最高分、累计击破、最佳连击、出航和通关次数
