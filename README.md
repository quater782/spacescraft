# SPACECRAFT // 星航双子

一款无需联网、可单人或本地双人游玩的 WebGL 3D 合作射击游戏。

## 运行

可以直接双击 `index.html` 运行。也可以在项目目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

桌面调试：

```bash
npm install
npm start
```

## 操作

- 单人模式：P1 使用 `WASD` 移动，P2 由 AI 僚机接管
- 本地双人：P1 使用 `WASD`，P2 使用方向键
- 双手柄：左摇杆移动
- `Esc` 暂停，`M` 静音，`Enter` 开始/重开

射击、能量技能和近距离救援均为自动触发，玩家只需控制移动。

30 分钟远征中共有八个只用方向键操作的“三选一”构筑节点：每章 25%/72% 处各一次，前两章 Boss 后各一次；左右选择、上下确认。22 项局内升级覆盖武装、机动/生存、Nova 与星链狂潮四条路线。首两次候选合计保证四路线全部出场，后续同时提供主路线追加和弱项补强，并用稀有/传说保底抑制极端欧非差距。航行种子会显示在构筑页与结算页，可用于复现同一局候选与战斗随机序列。

升级之间还存在 7 种“双子遗物协议”。第一次构筑选中组件后，配套件会在随后两次候选中确定性出现一次；完成后所有协议同时生效，产生高速侧翼齐射、屏障穿透、追踪蜂群、强化电弧、护盾新星、拾取晶弹或共振增幅等跨系统效果。协议选择与触发仍不需要战斗按键，并以矢量徽记、3D 轨道遗物、专属音效和任务报告清楚反馈。

同一枚航行种子也会生成一条三段生态航线。三章分别从 9 种生态中抽取场景；每个生态都使用全画幅三层星空、两层软体素星云、左右/顶部交替的宏观生态锚点、位于相对侧的远景天体、受限远景深度带和稀疏遗迹构成开放深空，彻底移除连续地板、导航网格、成对护栏和横贯画面的门架，并同步改变光色、敌军偏好和自适应 8-bit 配乐。玩家三机体采用灰蓝/暖灰哑光陶瓷主体、青蓝/珊瑚识别色、分段尖鼻和四段薄翼构成人类风筝形剪影；敌军由 7 类通用机体和 9 类生态原生种组成。推进轨迹、7 类弹幕武器、4 类防御核心、6 类智能芯片与4 类异常载荷共同形成 43,008 种完整构筑，并直接重塑尾部触须、武器颚、核心甲壳、眼阵和载荷器官。

四类战场拾取也会自动上线临时模块化 Buff：武库积木提高自动火力，纳米花簇加速并持续维修，神盾晶格拦截近身敌弹，通量磁环强化能量、牵引与光链。它们全部使用方块挂件、体素轨道、独立拾取音色和高清 HUD 反馈；终章敌人的霜冻、扰频与裂解载荷则用相同的建模语言预告减速、降射速或能量抑制。

每章开场还会出现三座实体 3D 星门。两架战机只需移动到同一航道即可自动锁定；七种航线协议会在支援、火力和高风险方案之间提供明确取舍，并实际改变即时奖励、敌军模块偏好、耐久、增援、弹速、得分倍率与本章音乐。单人模式的 AI 僚机会主动跟随 P1，超时则按当前航道自动跃迁，不增加任何战斗按键。

固定刷怪已经升级为种子化的 30 分钟远征导演：三章基础航行分别为 570、600、630 秒，总计 1,800 秒；每章再拆成三个强度递进的体素战区，完整一局包含 27 次编队事件、12 次动态目标和八个构筑节点。五类目标会在 14%/34%/58%/79% 进度从双子信标同步、星骸回收、移动信使护航、体素陨星生存与裂隙核心攻坚中组合。目标位置、类型和变体可复现，成功会给予双机共享奖励，错失也不会卡住航行；所有交互仍通过移动、接近、躲避或让自动火力对准目标完成。

0.25.0 把每章九轮战斗拆成“突入→交锋→杀伤区→释放”的压力波。0.26.0 让三章拥有不同节拍宽度和非比例压力向量，并加入会实际伤害及施加载荷的激光、恒速限角追踪弹、范围爆破种、九套死亡机能、4.8 倍耐久常规精英和致命机体碰撞。敌机不会在固定轮数后退场，而会持续占位、预警、攻击和盘旋直到被击破，并把尚未解决的战场压力带入 Boss 战；三章 Boss 基础耐久提高到 420/640/920，日耀枪、雷墙与双轨炮同样成为真实伤害束。普通敌弹仍按章节和节拍限制在 46–132 枚，战场可以激烈，但不会靠无限弹量破坏可读性。

0.27.0 把我方两个过强清场循环重做为可构筑系统。Nova 现在两机共享 120 能量，未构筑时每秒自动恢复 1.2，有效命中每次补充 0.65（全队基础预算 4.8/秒），只清除双机 76 半径内普通敌弹、对 96 半径内敌人造成伤害，不清激光，且每次释放至少间隔 14 秒；全屏净化必须选到传说卡。星链狂潮基线改为 6 秒机动窗口和 9 秒冷却，只提供移速 ×1.12 与操控 ×1.18，射速、伤害、光链、牵引和得分均保持 ×1；击破/拾取充能、输出和有限消弹都需通过卡牌解锁，遭遇/救援/Boss 阶段仅提供少量基础充能。

公平性不只依靠选牌保底。战斗、构筑、掉落、航线与表现现在各用一条 RNG 流；普通敌人掉落改用累积预算和武器/维修/护盾/能量四类洗牌袋，最长旱期不超过 13 击破。受弹、机体碰撞和拾取感应也分离为独立判定圈；55° 透视视场角、0.82 玩家机可见比例和分级敌机比例让同屏战术空间更大，而危险预警保持清楚。

远征之上还有五级“自适应威胁矩阵”。系统持续读取章节、战区、航程、合约、连击、近期击破、狂潮、共振、双机耐久、倒地和近期受击，把压力平滑调整为缓冲、巡航、交锋、激涌或极限；它会同步改变普通敌军的增援、耐久、航速、开火、弹速、瞄准误差和分数回报。首章前 8% 不会越过巡航级，残血或倒地会快速减压；熟练队伍在第一章第一个战区后就能主动把压力推高。HUD、3D 航道信标、战术节拍、8-bit 编曲、升降级音效和任务报告使用同一状态，无需增加任何操作键。

九个战区现在还会按同一航行种子各生成一种“活体星域异象”，一局恰好遍历九种且不会重复。晶寂场、离子花潮与彗星顺流组成首章安全池；极光洋流、重力透镜、棱镜风暴、磁星潮汐、时序裂隙与虚空激涌逐章开放更强的可反向操控力场。异象会同时改变敌军节奏、弹道漂移、玩家机动、自动射速、能量恢复、拾取牵引、掉落和收益，并以九套独立 Toon+Glow 体素地形、左侧 HUD、切换音簇、动态 8-bit 动机和完整结算航迹反馈。首章三种异象只缓和或保持敌军压力，仍保留开局六秒禁火。

首次出航会显示三步教学。设置页支持简体中文/英文即时切换、独立音乐/音效音量、三档 3D 渲染质量、屏幕震动、闪光强度和高对比敌方弹幕；选择与生涯统计会自动保存在本机。语言切换覆盖战斗 HUD 与当前任务结算，无需重启游戏。

主菜单的“双子机库”提供三种拥有独立 3D 几何与战斗参数的机体，以及四枚偏向能量、防御、救援或协作的核心模组。完成航行会获得星尘，用于永久解锁机体和模组；旧版本存档会自动迁移。

机库中的“恒星天赋网格”进一步提供 9 个跨航行永久节点。矢量机动、自动武装与双子共振各有三层依赖链，分别强化移动/碰撞容错、自动火力/超新星循环，以及光链/救援/共享护盾；星尘购买、前置状态和实际战斗属性会写入 v5 本地存档，旧存档无损补齐空网格。

战斗中的双机共振仍会自动积蓄星链能量，但未构筑状态只保留连线充能与遭遇/救援/Boss 阶段的少量事件能量。满槽后自动进入星链狂潮，在 6 秒内以速度和操控鼓励双机换位；击破充能、拾取充能、过驱火力和光链偏转是四类明确的后续构筑。玩家仍然只需要控制方向。

机库还可签署巡航、风暴或过载三种航线合约。高难合约会同时改变敌军耐久、弹速、增援节奏、我方性能和结算倍率；八枚本地星航勋章记录关键里程碑，并使用稳定 ID 为后续 Steam 成就映射做准备。

## 技术说明

- Three.js WebGL2 透视相机、原生分辨率 + SMAA、最小 0.12 世界单位粗体素、按色缓存的 `InstancedMesh`、三阶 `MeshToonMaterial`、每体素轻辉光、HDR 能量批次、五级 Unreal Bloom 与动态点光源
- 480×270 透明 HUD，3D 场景根据屏幕像素密度动态渲染
- Web Audio API 实时合成多轨 8-bit 配乐与音效
- 固定时间步游戏循环，避免不同刷新率改变游戏速度
- 玩家、敌军、Boss、分段拖尾弹幕、拾取物、星门与九套动态 3D 微缩世界统一使用 `BoxGeometry` 组合；玩家航空战机构造器与敌军异形器官构造器完全分离，功能模块改写外轮廓，不以手写面片或表面微方块堆砌造型
- 单人 AI 会预判弹道、保持共振队形、集火目标并优先救援
- 1,800 秒基础远征、九个强度战区、27 次分层编队事件与八次局内构筑；Boss 拥有三阶段招式、护盾转场与镜头演出
- 五级自适应威胁矩阵、1.25 秒迟滞、首章/残血/倒地保护、战斗与得分耦合、3D 航道预告和双语任务遥测
- 四段循环压力波、七职责六态敌军 AI、六种智能器官、六种编队、激光/追踪/爆破/死亡机能、46–132 敌弹预算与持续追猎
- 九种确定性战区异象、首章安全池、可对抗航行力场、敌我非对称弹道耦合、资源/音乐/3D/HUD/结算闭环
- 星尘局外经济、三种可选机体、四枚核心模组和本地解锁存档
- 三档数据驱动航线合约与八枚本地星航勋章
- 统一中英双语文案目录、v5 天赋/语言存档迁移与自动缺失键检查
- 战斗/构筑/掉落/航线/表现五路独立随机源、22 项四流派升级、稀有/传说保底、7 种两件套遗物协议与确定性配套窗口
- 9 种确定性星域生态、16 个有机船体家族、九种生态原生种、六维 43,008 种模块化敌军构筑、程序化 3D 地标与生态自适应音乐
- 4 种自动 Buff、3 种敌方异常载荷、体素挂件/弹体/状态碎片与动态 8-bit 信号
- 每章三座可驾驶进入的 3D 星门、7 种风险/奖励协议、单人 AI 汇合与航线自适应音乐
- 五类模块化动态遭遇、每局十二个种子目标、体素场景实体、共享奖励与自动失败回退
- 9 节点恒星天赋网格、三条前置依赖链、永久战斗效果与星尘长期成长
- 120 能量双机共享 Nova、局部清弹/伤害圈、14 秒冷却与可构筑全域净化
- 全自动星链狂潮、6 秒机动爆发、9 秒冷却与卡牌解锁的充能/输出/偏转
- 本地生涯记录包含最高分、累计击破、最佳连击、出航和通关次数
