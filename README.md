# SPACECRAFT // 星航双子

一款无需联网、可单人或本地双人游玩的 WebGL 3D 合作射击游戏。

## 运行

可以直接双击 `index.html` 运行。也可以在项目目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。

桌面调试：

```bash
npm install
npm start
```

## 操作

- 单人模式：P1 使用 `WASD` 移动，P2 由 AI 僚机接管
- 本地双人：P1 使用 `WASD`，P2 使用方向键
- 双手柄：左摇杆移动
- `Esc` 暂停，`M` 静音，`Enter` 开始/重开

射击、能量技能和近距离救援均为自动触发，玩家只需控制移动。

首次出航会显示三步教学。设置页支持简体中文/英文即时切换、独立音乐/音效音量、三档 3D 渲染质量、屏幕震动、闪光强度和高对比敌方弹幕；选择与生涯统计会自动保存在本机。语言切换覆盖战斗 HUD 与当前任务结算，无需重启游戏。

主菜单的“双子机库”提供三种拥有独立 3D 几何与战斗参数的机体，以及四枚偏向能量、防御、救援或协作的核心模组。完成航行会获得星尘，用于永久解锁机体和模组；旧版本存档会自动迁移。

机库还可签署巡航、风暴或过载三种航线合约。高难合约会同时改变敌军耐久、弹速、增援节奏、我方性能和结算倍率；八枚本地星航勋章记录关键里程碑，并使用稳定 ID 为后续 Steam 成就映射做准备。

## 技术说明

- 原生 WebGL 真实透视相机、3D 几何模型、深度与光照
- 480×270 透明 HUD，3D 场景根据屏幕像素密度动态渲染
- Web Audio API 实时合成多轨 8-bit 配乐与音效
- 固定时间步游戏循环，避免不同刷新率改变游戏速度
- 单人 AI 会预判弹道、保持共振队形、集火目标并优先救援
- 三章各有三种编队事件和一场精英战；Boss 拥有三阶段招式、护盾转场与镜头演出
- 星尘局外经济、三种可选机体、四枚核心模组和本地解锁存档
- 三档数据驱动航线合约与八枚本地星航勋章
- 统一中英双语文案目录、v4 语言存档迁移与自动缺失键检查
- 本地生涯记录包含最高分、累计击破、最佳连击、出航和通关次数
