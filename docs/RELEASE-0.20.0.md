# 0.20.0 发行说明：Boss 有机体锻造

0.20.0 的 Major 主题是把三章 Boss 从“放大的普通异形舰”升级为三套独立、会随阶段生长的大型像素积木有机体，并让每章 Boss 的弹幕拥有自己的立体结构。本版本代号为 Boss Organism Forge，延续高饱和无黑舰体、三阶 Toon 与克制 Glow，仍不是 Steam 发布候选版。

## 三套独立 Boss 有机体

- 第一章“星蚀巡洋体”重做为展开花瓣/魟翼的宽体掠食者：中轴脊、三段翼瓣、外侧发光翼尖和双推进器构成连续轮廓。
- 第二章“雷核巨像”重做为厚实的中央长枪与双侧熔炉肩舱：不再使用厚度 0.09 的长杆，宽体炮肩、能量塔和外侧热核成为主体结构。
- 第三章“虚空织主”重做为具有中央负空间的双体冠舰：两条长轴躯体、宽弧骨翼、外侧刃冠和中央虚空心核形成与前两章完全不同的剪影。
- 三套 Boss 不再调用普通敌舰的弯月或触须构造器，也不复用玩家战机的机鼻/机翼/尾翼。

## 阶段生长与专属弹体

- 每套 Boss 的第二、第三阶段会长出不同的大型器官：花瓣背鳍、熔炉塔/热核肩、虚空冠/外侧刃翼；阶段变化不再只依赖护罩提示。
- 第一章 Boss 弹体为双色展开花瓣，第二章为带侧翼的长轴雷枪，第三章为三臂旋转虚空棱体；全部沿实际速度方向生成三节体积拖尾。
- Boss 发射的弹体写入稳定 `bossStage`/`bossPhase` 语义，渲染器据此切换章别与阶段外形；普通敌弹路径不受影响。
- 3D Canvas 新增 `data-boss-families="3-organic-phase-forms"` 契约，静态门禁拒绝三套旧细杆尺寸和普通异形附肢复用。

## 三阶段视觉矩阵

- 新增 localhost `qa-boss-gallery` 与 `qa-boss-phase=1|2|3`，可在干净星空/网格中同屏比较三章 Boss 以及对应专属弹体。
- 新增 `npm run smoke:bosses`：真实 Electron/WebGL 依次打开三个阶段，验证三套 Boss、大型有机模块、Toon+Glow、饱和无黑色、WebGL、50 FPS 下限和零应用控制台错误，并输出三张截图。
- 三阶段实测分别为 52、60、60 FPS，全部 WebGL true、0 应用控制台错误；三张近景截图已人工复核，阶段器官增长、独立剪影和三类弹体均可见。
- 当前宿主的内置浏览器控制仍有初始化冲突，因此未列为通过；视觉证据来自真实 Electron/WebGL 窗口。
