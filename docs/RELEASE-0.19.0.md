# 0.19.0 发行说明：有机剪影锻造

0.19.0 的 Major 主题是把“模块化”从细杆与小挂件改成真正参与机身外轮廓的大型器官，并建立一套可以一次看到三架玩家战机和七类敌舰的近景验证矩阵。本版本代号为 Organic Silhouette Forge，继续使用 Three.js 实例化立方体、三阶 Toon 与克制 Glow，仍不是 Steam 发布候选版。

## 战机与敌舰重塑

- 彗星、壁垒、脉冲三架战机进一步拉长纵轴并收窄截面；壁垒从短宽装甲块改为细长重型攻击机，脉冲成为更明确的针形截击机。
- 军械与神盾 Buff 从细导轨升级为嵌入翼根和翼缘的宽体结构，仍保持自动触发且不增加战斗键。
- 七类敌舰继续保持独立异形语法；甲壳壁垒体明显收窄拉长，远端敌舰新增温和透视补偿，避免真实战斗中剪影缩成不可读小点。
- 敌我方向保持相反：玩家机头朝航线前方，敌舰绕 Y 轴 180° 来袭。

## 大型有机模块

- 推进模块重做为宽体尾肩、引擎罩、非对称漂移鳍和大型推进器官；删除织行/漂移模块重复生成的细触须挂件。
- 双联、狙击、环轨与脉冲武器改为厚实的分叉颚、中央长刺、宽弧骨翼与整合炮口。
- 装甲、屏障与易爆核心成为背甲、侧肋、能量桥和搏动心核；AI 与冰冻/干扰/破译载荷改为眼阵、感知冠、宽鳃和锯鳍。
- 3D Canvas 新增 `data-module-anatomy="integrated-large-form"` 契约；静态门禁拒绝旧细杆尺寸回退。

## 可复现近景矩阵

- 新增仅 localhost 生效的 `qa-model-gallery`，同屏展示三种玩家机体和七类敌舰，并固定七套具有代表性的推进/武器/核心/AI/载荷组合。
- 新增 `npm run smoke:models`：真实启动 Electron/WebGL，断言 3+7 家族、Toon+Glow、饱和无黑色、大型有机模块、50 FPS 下限和零应用控制台错误，并生成干净近景截图。
- 本轮实测近景矩阵为 53 FPS、WebGL true、0 应用控制台错误；人工复核确认背景遮挡和 DOM 提示已移除，三架玩家战机与七类敌舰可在同一透视场中比较。
- 当前宿主的内置浏览器控制仍有初始化冲突，因此未列为通过；视觉证据来自真实 Electron/WebGL 截图。
