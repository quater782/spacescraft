# 0.22.0 发行说明：30 分钟远征导演

0.22.0 的 Major 主题是把原先 126 秒的演示型流程升级为有实际内容密度的 30 分钟 Roguelike 远征。本版本代号为 30-Minute Odyssey Director：三章基础航行合计精确 1,800 秒，并同步扩展战区、编队、动态遭遇、章中构筑、3D 转场与音乐强度，而不是只拉长空白计时器。本版本仍不是 Steam 发布候选版。

## 1,800 秒与九战区

- 三章正式航行分别为 570、600、630 秒，基础战斗路线正好 30 分钟；三场 Boss、星门选择和构筑暂停使实际完整一局略长于 30 分钟。
- 新增独立 `src/director.js`，集中保存正式时长、事件/遭遇/构筑阈值、九战区映射、强度曲线和 QA 时间倍率，避免游戏循环散落魔法数字。
- 每章按进度拆成三个战区。战区提升会逐层增加敌军并发预算与刷新节拍，并把 8-bit 根音抬升两个半音；边缘光和航道速度同步增强。
- 3D 场景新增持续流动的章内战区门架；切换时一座大型双色 Toon+Glow 体素跃迁门从远处推进到镜头，全部继续使用共享 `BoxGeometry` 实例批次。

## 27 次编队、12 次目标、八次构筑

- 三章原有九套编队模板扩展为三个 tier，每章在 8%–88% 进度触发九次，完整远征 27 次；高阶 tier 追加双侧护卫，仍保持章别剪影和首章安全规则。
- 动态遭遇从每章两个扩展为四个，固定在 14%/34%/58%/79% 进度；同类不会连续出现，连续目标也会切换航道。第一章仍只使用信标、回收和护航教学池。
- 每章 25%/72% 处新增章中构筑，前两章 Boss 后保留章间构筑，完整一局八次。构筑继续只用方向键；章中确认返回当前战区，章间确认才推进章节。
- HUD 现在显示全局战区 1/9、编队事件 1/9、遭遇 1/4 和构筑 1/8。诊断属性公开 1,800 秒目标、战区、事件、遭遇、构筑次数和上下文。

## 动态验证

- `scripts/verify-director.mjs` 精确验证 570/600/630、1,800 秒、9/27/12/8 总数、全部有序相对阈值、正常 1×、快速 90×、Boss 状态 180× 与体素画廊 1× 隔离。
- `npm run smoke:director` 在真实 Electron/WebGL 隐藏窗口中使用 90× 压缩模拟第一章；本轮实际捕获战区 1/2/3、事件 9/9、遭遇 4/4、两次 `mid-stage` 构筑并进入 Boss。
- 同一会话记录 Three.js `three-r185-instanced-voxel`、`9-progressive-voxel-gates`、60 FPS 和零应用控制台错误。
- 这组验证证明正式时长配置和压缩运行路径成立；它不冒充一次正常 1×、含三 Boss 和所有选择暂停的完整 30 分钟实玩/性能长测。
