# 0.9.0 发行说明：模块化星域远征

0.9.0 的 Major 主题是让每次三章航行拥有不同生态与敌军组合，而不只是沿固定背景刷固定敌人。同一枚航行种子现在同时决定三段生态航线、敌军模块与局内构筑候选；两名驾驶员仍然只控制方向，自动射击、自动技能和自动救援不变。本版本代号为 Expedition Alpha，仍不是 Steam 发布候选版。

## 玩家体验

- 三章各拥有三种生态候选，共 9 种星域：糖晶花海、棱晶果园、彗潮海湾、极光铸场、雷鸣工坊、云鲸礁群、蚀月嘉年华、虹棱墓园与虚空温室。
- 每种生态使用不同天空、雾、网格、星光、强调色和程序化 3D 地标，并调整敌型偏好、敌军耐久、增援节奏、敌弹速度、音乐 BPM 与调式。
- 敌机由移动、武器、核心三槽组装，每槽四种模块，可形成 64 种完整构筑。蛇形、突进和漂移改变航迹；双联、狙击和环轨改变弹幕；装甲、屏障和爆裂核心改变击破方法。
- 模块不是隐藏数值：3D 敌机拥有翼组、引擎、漂移环、炮管、轨道环、装甲板、能量罩与发光核心，首次发现新组合时 HUD 会显示中英模块扫描。
- 屏障破碎和爆裂连锁加入独立音色、粒子和震动。敌军武器也按脉冲、双联、狙击、环轨使用不同 8-bit 发射声。
- 章节卡显示当前生态及说明，顶部 HUD 持续显示生态名，结算报告记录完整生态航线。

## 难度与公平性

- 第一章前 36% 只生成侦察机，前 40% 只使用标准航行、脉冲炮和轻型核心，保留开局 6 秒敌军禁火。
- 第一章三种生态均不提高敌弹速度或刷怪率，敌军耐久倍率上限为 1.02；并发敌军上限仍由章节进度硬限制。
- 模块复杂度随章节、进度和精英身份逐步开放；后期才会完整混合移动、武器与核心三槽，避免开局信息过载。
- Boss 吃生态耐久与弹速系数，但阶段护盾、弹幕节奏和清弹转场继续提供稳定喘息窗口。

## 工程与可靠性

- 新增 `src/expedition.js`，把生态、敌型权重和模块组装从主循环中分离为可独立验证的确定性规则层。
- `src/renderer3d.js` 读取敌军模块和生态对象，使用代码生成 WebGL 几何；本版本没有新增会因放大而模糊的位图功能图标。
- `#game` 新增 `data-route-signature`、`data-biome`、`data-enemy-variants` 与 `data-active-builds`，便于复现和观察模块分布。
- `scripts/verify-expedition.mjs` 覆盖 9 种生态、每章三候选、64 种唯一构筑、数值合法性、种子复现、第一章安全包络、后期船体/模块多样性、精英核心约束和 3D 接线。
- 本轮 `npm run verify` 覆盖 20 份 Markdown、291 个引用键 × 2 种语言、15 项玩家升级、9 种生态、64 种敌军构筑、JavaScript 语法与正式依赖；`npm audit --omit=dev` 为 0 个漏洞。

## 已知验证缺口

本轮内置浏览器会话在初始化阶段被当前宿主运行环境拦截，因此没有把九种生态的可见 WebGL 画面、敌军 3D 外挂、模块扫描 HUD 或完整三章运行记为已通过。规则测试、静态集成、双语、包内内容、EXE/ZIP 哈希和归档完整性均已验证；正式候选版仍需在浏览器及 Windows 10/11 实机完成单人/双人、双语言、双手柄、九生态抽样、正常时长三章和长时间稳定性回归。
