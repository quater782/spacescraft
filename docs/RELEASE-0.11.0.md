# 0.11.0 发行说明：动态星域遭遇

0.11.0 的 Major 主题是让关卡本身要求玩家改变飞行方式，而不再只是等待下一批敌人。每章现在会插入两个可复现目标：靠近、收集、跟随、躲避或对准目标，都只使用移动输入并与自动战斗自然结合。五类遭遇拥有独立 3D 实体、奖励、失败回退、AI 行为和音乐层；同一枚航行种子会复现完整六目标计划。本版本代号为 Encounter Alpha，仍不是 Steam 发布候选版。

## 玩家体验

- 双子信标要求一架或两架战机驶入能量环；双机同时同步速度更快，离开范围会缓慢失去进度。
- 星骸采集场把七枚旋转星骸铺入航道，触碰即可自动回收；达到目标后两机武器同步升级。
- 云鲸信使会在下半场持续改变方向，两机靠近可维持护航链并获得维修和护盾。
- 赤焰陨星潮从第二章开放；复合体素陨石拥有可预判航迹，命中沿用护盾和受击无敌，容许一次真实受击。
- 棱镜裂隙攻坚从第二章开放；玩家只需移动到核心下方，常规自动武器、齐射和构筑伤害都会拆解目标。
- 成功获得共享资源与计分，错失只会失去奖励并立即继续，不会新增确认键、失败惩罚或流程阻塞。

## 程序化关卡与公平性

- `generateEncounterPlans(seed)` 使用独立随机盐生成三章各两个不重复目标，并固定 30%/64% 出现点、不同航道、四种几何变体和章节强度。
- 第一章池仅包含无直接伤害的信标、星骸和护航，并把同期刷怪倍率限制在 0.78–0.90；危险陨星和高压裂隙从第二章才进入池。
- 所有目标都有明确倒计时；Boss 到时会安全回收未完成实体。遭遇对象不会残留到星门、构筑或下一章。
- 单人 AI 使用与玩家相同的速度、碰撞和受击规则，但会识别目标位置、追逐最近星骸、对准裂隙并预测陨石落点。
- 遭遇奖励受当前合约与星门得分倍率影响；能量、武器、维修和护盾同步结算到双机。

## 3D、界面与音频

- WebGL 新增能量信标、护航无人机、旋转星骸、三块组合陨石和双层裂隙护环，全部复用代码网格与光照材质，没有新增位图功能图标。
- HUD 继续以 480×270 逻辑坐标和 DPR 高清缓冲绘制，实时显示目标序号、名称、文本、进度/耐久/容错及倒计时；任务报告记录六个成功或错失结果。
- 遭遇在生态与星门编曲上继续叠加 BPM、调式和短促信号旋律；Boss 层级仍具有最高节奏密度。
- 开始、推进/命中、陨石冲击、完成与错失使用不同音高走向、波形、噪声频段和包络，拾取与目标反馈不会退化为同一个短音。

## 工程与验证

- `src/expedition.js` 导出 5 个冻结遭遇定义、确定性计划和纯结果判定；`src/game.js` 拥有运行态、AI、碰撞、奖励和 HUD；`src/renderer3d.js` 仅把快照绘制为 3D。
- 新增 `data-encounter-plan`、`data-active-encounter`、`data-encounter-progress`、`data-encounter-objects` 与 `data-encounter-history`。
- localhost 可用 `qa-encounter=relay|salvage|courier|meteor|rift` 强制覆盖目标；正式域名和 Electron 文件协议无法启用。
- 新增 `npm run smoke:electron`：以隔离临时 profile、本机随机端口和隐藏真实窗口启动游戏，发送方向输入、读取稳定诊断、验证 WebGL/控制台并输出截图。
- `npm run verify` 覆盖 22 份 Markdown、357 个引用键 × 2 种语言、15 项升级、9 种生态、7 种航线、5 类/6 个动态目标、64 种敌军构筑、JavaScript 语法与正式依赖；`npm audit --omit=dev` 为 0 个漏洞。
- Electron 冒烟实际得到 60 FPS、2142×1203 HUD、`relay:success`、`webgl: true`、`consoleErrors: 0`；实际截图已检查到透视网格、3D 信标/战机和清晰 HUD。

## 已知验证缺口

本轮真实 Electron 运行覆盖了首章信标的 WebGL 画面、方向输入、成功奖励和诊断闭环；其余四类目标只有规则、静态集成、双语和包内内容证据，尚未逐一完成可见交互。正式候选版仍需在可交互桌面及 Windows 10/11 实机完成星骸/信使/陨星/裂隙、单人/双人、双语言、双手柄、正常时长三章和长时间稳定性回归。
