# 0.10.0 发行说明：三岔星门航线

0.10.0 的 Major 主题是把“关卡随机”从后台数值变化升级为玩家能看见、能驾驶进入、会持续改变本章战斗的选择。每章开场出现三座实体 WebGL 3D 星门；两架战机只需移动到同一航道便会自动锁定。七种协议把即时收益、敌军生态和得分风险组合成可理解的分支，同时保持自动射击、自动技能和自动救援。本版本代号为 Branching Alpha，仍不是 Steam 发布候选版。

## 玩家体验

- 每章从确定性计划中展示支援、火力和高风险各一条路线；左右位置每局会变化，同一 `seed` 可完整复现三章候选。
- 星铸武库与共振回廊强化武器或双机光链；泡泡圣所与星骸打捞带提供续航；红线激流、棱镜狙击场和翠星异变以更强敌军偏好换取伤害、能量、护盾或更高得分。
- 两机进入同一门心并保持 0.68 秒自动跃迁；5.8 秒内未汇合则依据当前平均航道选择，游戏不会因犹豫卡死。
- 单人模式的 AI 僚机识别 P1 当前航道并主动汇合；本地双人则保留共同决策，不增加确认、射击或技能按键。
- 三座星门由双层发光环、旋转体素与能量核心构成；选中、汇合和锁定都有独立光效、震动及 8-bit 分层音效。
- HUD 三卡同时显示协议类别、说明、风险、奖励与得分倍率；章节卡和任务报告持续记录已经锁定的路线。

## 战斗、音乐与公平性

- 协议可偏向双联炮、环轨弹舱、狙击矛、突进引擎、装甲、屏障或爆裂核心，并独立改变耐久、增援、弹速与得分倍率。
- 即时奖励直接作用于两架战机；棱镜伤害和共振距离只在当前章节生效，维修、护盾、能量与武器奖励在锁定时结算。
- 8-bit 音序器在生态 BPM/调式上叠加协议偏移，Boss 战继续动态提升鼓、低音和高音密度，使路线选择也能被听见。
- 第一章前 40% 会把协议耐久、弹速和增援倍率钳制到不高于 1.0；既有开局 6 秒禁火、标准早期模块、侦察机保护与敌军并发上限保持不变。
- 章节切换会安全恢复倒地飞船的最低耐久并给予无敌时间，避免进入星门选择时保留不可操作的倒地状态。

## 工程与可靠性

- `src/expedition.js` 新增 7 个冻结协议、独立随机盐生成的三章候选，以及可单测的双机航道/汇合判定；表现随机源仍不会改写玩法序列。
- `src/renderer3d.js` 使用现有网格和材质系统绘制实体星门；`src/game.js` 接入奖励、难度、AI、分数、音乐、音效、HUD 与结算。
- 所有新增图形均为 WebGL 几何或随设备像素比渲染的 Canvas，没有新增会因放大而模糊的位图功能图标。
- 新增 `data-path-plan`、`data-active-path`、`data-path-options`、`data-path-selection` 和 `data-path-history`；localhost 可用 `qa-path=0|1|2` 强制覆盖三条航道。
- `scripts/verify-expedition.mjs` 验证 7 协议唯一性、每组类别覆盖、种子复现/分化、五种航道判定、早期安全、协议模块偏好、单人 AI 与 3D 接线。
- `npm run verify` 覆盖 21 份 Markdown、331 个引用键 × 2 种语言、15 项升级、9 种生态、7 种协议、64 种敌军构筑、JavaScript 语法和正式依赖；`npm audit --omit=dev` 为 0 个漏洞。

## 已知验证缺口

Electron 桌面壳已成功启动且未输出应用错误，但当前 Mac 处于锁定状态，自动化无法读取或操作可见画面；内置浏览器会话也无法在当前宿主完成初始化。因此本轮没有把三座星门的实际画面、单人/双人可见交互、七协议效果或完整三章运行记为已通过。规则测试、静态集成、双语、Windows 包内内容、EXE/ZIP 哈希和归档完整性均已验证；正式候选版仍需在可交互桌面及 Windows 10/11 实机完成正常时长、双模式、双语言、双手柄、三航道、七协议抽样和长时间稳定性回归。
