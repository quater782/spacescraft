# 0.13.0 发行说明：星链狂潮

0.13.0 的 Major 主题是为“只控制方向”的合作射击建立一个持续追求、自动爆发、可延长且可结算的爽感循环。双机通过编队和积极完成战场事件积蓄星链能量，满槽后自动进入狂潮；没有新增手动射击或技能按键。本版本代号为 Starlink Rush Alpha，仍不是 Steam 发布候选版。

## 自动狂潮循环

- 双机处于共振距离时每秒获得 1.8 充能；非共振时仅每秒衰减 0.22，短暂闪避不会毁掉已有进度。
- 普通击破、精英额外奖励、拾取、动态遭遇成功、自动救援和 Boss 阶段分别提供 3.4、8、6、14、18、10 基础充能；事件发生时若双机共振，再获得 35% 编队奖励。
- 充能达到 100 后自动启动 7.5 秒狂潮，现有敌弹被清空、双机各恢复 18 能量；无需玩家确认，也不占用任何方向键之外的输入。
- 狂潮击破会增加链数并延长 0.12 秒，精英增加 3 链并延长两次，最长持续 10 秒；结束后按章节、合约与星门得分倍率结算链奖励。
- 任务提前结束时会结算仍在进行的狂潮，任务报告显示触发次数、最佳链和最近一次奖励。

## 战斗、3D 与界面

- 自动武器在狂潮期间获得 1.38 倍射速、1.26 倍伤害和 1.5 倍得分；共振光链获得 1.65 倍频率与 1.42 倍伤害，拾取牵引距离增加 90 逻辑像素。
- 双机连线每 0.16 秒检查一次穿越弹幕，熔解距线段 13 逻辑像素内的敌弹；任一战机倒地时该防线暂停，避免倒地坐标制造隐形保护。
- 两架战机各拥有双层旋转 WebGL 能量环、六枚体素轨道碎片与独立色彩，双机中央生成旋转八面体共振核心和半透明能量球。
- 高清 Canvas HUD 在底部显示自然充能百分比；爆发后切换为脉冲倒计时和链数，颜色会在高链时变为金色。图形全部来自 WebGL 几何或 Canvas 绘制，没有新增位图功能图标。
- 简体中文和英文目录新增狂潮 HUD、启动/结算提示与任务报告文案；七项 `data-rush-*` 属性提供可机器读取的状态。

## 8-bit 动态音频

- 狂潮把当前生态/星门/遭遇/Boss 编曲的 BPM 再提高 18，并把音序密度提高到 1.38。
- 高音轨增加独立八度琶音，鼓组增加错位第二底鼓，高通噪声形成持续推进纹理；Boss 音乐仍保留其阶段密度，因此狂潮 Boss 战具有叠加层次。
- 启动音效由低频核心、上行方波和宽噪声组成；每四链反馈使用短促高音与噪点；结算使用下行旋律和低频收束，与射击、拾取、装备及遭遇音色可辨。

## 平衡与安全

- 第一章没有增加敌军数量、耐久、伤害、弹速或刷怪倍率；狂潮完全是玩家侧奖励。
- 6 秒开局禁火、第一章标准敌军构筑、无伤害学习遭遇、慢弹与并发敌军上限全部保留。
- 星门选择、章节转场、菜单、暂停、构筑和结果界面冻结充能；更新逻辑继续运行在 `STEP = 1 / 60` 固定时间步。
- 狂潮规则不读取随机数；3D 轨道相位和粒子只使用表现时间/表现随机源，因此不会扰动玩法 RNG 与同种子复现。

## 工程与验证

- 新增 `src/rush.js`，把阈值、六类事件、共振增益、衰减与战斗倍率从运行时分离为可独立验证的纯规则。
- 新增 `scripts/verify-rush.mjs`，验证六类事件、边界钳制、共振加速、非战斗冻结、自动战斗倍率、诊断与 3D 接线。
- `npm run verify` 通过：24 份 Markdown、392 个引用键 × 2 种语言、JavaScript 语法、15 项局内升级、9 项长期天赋、9 种生态、7 种航线、5 类动态遭遇、64 种敌军构筑和正式依赖审计均通过，0 个漏洞。
- `npm run smoke:electron` 在隔离 profile 中实际购买“矢量推进器”，随后自动启动狂潮并只用方向输入完成信标；记录为 60 FPS、2142×1203 HUD、`rushActive: true`、`rushCount: 1`、`relay:success`、`webgl: true` 和 `consoleErrors: 0`。同一会话继续等待完整结算，确认 `rushActive: false`、最佳 4 链与 +360 奖励。
- 实际截图已人工检查：透视网格、3D 战机、双层彩色能量环、体素轨道碎片、中央核心、中文倒计时/链数和高清 HUD 均可见。Codex 内置浏览器运行时在创建会话前无法初始化，未把该路径记为通过。
