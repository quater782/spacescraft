# 0.18.0 发行说明：立体霓虹生态

0.18.0 的 Major 主题是把九个星域从静止远景升级为真正参与飞行感的 3D 像素积木微缩世界，并把子弹与爆炸从单块提示升级为有方向、有速度感的 Toon+Glow 体积特效。本版本代号为 Neon Diorama Worlds，继承 0.17.0 的高饱和无黑舰体、航空战机比例、独立异形器官和奥卡姆块数预算，仍不是 Steam 发布候选版。

## 九套动态 3D 微缩世界

- 新增会从远景向镜头推进的航路坐标与两侧信标，近景航标、中景生态、远景地标形成三层纵深；全部仍由实例化 `BoxGeometry` 组成，不使用 Plane 或光滑原语。
- 糖晶花海、棱晶果园、彗潮海湾、极光铸场、雷鸣工坊、云鲸礁群、蚀月嘉年华、虹棱墓园与虚空温室现在分别拥有独立构造分支，不再由多个生态共享同一组静态摆件。
- 花簇、晶簇、彗流、分段极光、齿轮轴、云礁、嘉年华星门、棱柱墓碑与发光枝晶使用少量较大的彩色积木建立清楚剪影；颜色直接来自生态的 accent/secondary 调色板。
- 第三章旧有近黑巨墙改成双色异形城塞；蚀月从黑色方块球改成紫红色 Toon 星体与淡紫环光，避免用黑色隐藏造型。
- 第一、二、三章公共地标也改为随当前生态换色的伴飞星体、轨道铸架与双塔城塞，九条航线的世界光色保持一致。

## 弹体、命中与爆炸

- 玩家标准弹、重弹、追踪弹和相位长枪新增 2–3 节渐缩拖尾；敌军脉冲、双联、狙击与环轨弹使用不同宽度、长度、偏移与载荷色拖尾。
- 拖尾按弹体实际速度方向旋转，不再是与运动脱节的静态小方块；低画质自动压缩为一节，限制高弹幕场景实例预算。
- 命中与爆炸粒子按速度拉伸成体积光屑，大碎片增加暖白余辉节；粒子生命周期同时控制长度和亮度，替代“一粒一个立方体”的扁平特效。
- 3D Canvas 新增 `data-world-depth-layers="3"`、`data-biome-dioramas="9"` 与 `data-projectile-vfx="segmented-toon-trails"`，桌面冒烟会拒绝场景或特效契约回退。

## 可复现视觉矩阵

- 新增仅 localhost 生效的 `qa-biome=<id>`，可以把九个生态中的任意一个强制到第一章；无效 ID 会被忽略，不影响正式玩法。
- 新增 `npm run smoke:biomes`：真实启动隔离 Electron/WebGL，依次进入九个生态，验证生态 ID、三层纵深、九套微缩世界、分段拖尾、Toon+Glow、无黑舰体、WebGL、45 FPS 下限和零控制台错误，并输出九张截图到系统临时目录。
- `scripts/verify-renderer3d.mjs` 现在静态检查九个独立生态分支、流动航路、拖尾、速度光屑、QA 覆盖和版本契约。
- 九生态矩阵实测均为 60 FPS、WebGL true、0 控制台错误；完整自动战斗冒烟同样保持 60 FPS、2142×1203 HUD，并验证六维 7,168 敌型、四 Buff、Debuff、协议、狂潮和方向输入遭遇没有回归。
- 当前宿主的内置浏览器控制运行时仍存在初始化冲突，因此未列为通过；视觉证据来自真实 Electron/WebGL 窗口与逐生态截图。
