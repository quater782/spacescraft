# 0.4.0 发行说明：战役事件与 Boss 阶段

0.4.0 把三章从连续刷怪升级为有节奏标识的事件战役，并完善 Boss 的三阶段反馈。该版本仍是 Campaign Alpha，不是 Steam 发布候选版。

## 战役结构

| 章节 | 事件一 | 事件二 | 精英事件 |
| --- | --- | --- | --- |
| 糖果星云 | 楔形突击 | 交叉火线 | 糖核守卫 |
| 齿轮云城 | 运输护航 | 旋翼阵 | 铸云监工 |
| 终焉城堡 | 虚空雷区 | 钳形包围 | 王座先锋 |

事件会使用不同的入场位置、横向速度和编队节奏。精英敌机拥有扩大的 3D 模型、发光环、额外耐久、分层火力和更高积分奖励。

## Boss 演出

- 每名 Boss 根据剩余耐久进入三个命名阶段。
- 阶段转换会短暂清除敌方弹幕、提供转场护盾，并触发镜头推进、HUD 提示和专属音效。
- 受击闪白和护盾球体让命中状态在 3D 场景中可直接辨认。
- Boss 登场前会清理上一事件的残留杂兵，消除无法预判的弹幕叠加。

## 可读性与发行资源

- 新增标准/高对比敌方弹幕配色；高对比模式使用黄色弹体与强化辉光。
- 按钮、选择框和滑杆都拥有清晰的键盘焦点轮廓。
- 桌面图标由 SVG 母版生成七档 Windows ICO，并附 256px PNG 与完整 ICNS。

## 验证记录

- 正常速度：验证第一章三个事件、精英战、Boss 三阶段、AI 两次救援和第二章转场，采样 60 FPS。
- 快速战役：完整通过三章，九个事件与三名 Boss 均完成，结果为 `QA CAMPAIGN CLEAR`；结束时两机生命为 5/7，采样 60 FPS。
- 控制台：测试期间无日志、警告或错误。
- 静态检查：`src/game.js` 与 `src/renderer3d.js` 语法通过；正式运行依赖审计为 0 个漏洞。
- 存档边界：快速测试不会写入出航次数、通关次数、最高分或其他生涯统计。
