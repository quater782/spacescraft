# 0.15.0 发行说明：体素模块工坊

0.15.0 的 Major 主题是建立一套真正可扩展的体素积木视觉和战斗模块语言。旧手写 WebGL 渲染器及其面片模型已被 Three.js 0.185.1 架构取代；玩家战机、敌军、Boss、弹幕、拾取物、星门、遭遇物与 3D 背景全部重建。敌军从 64 种三槽组合扩展为 1,024 种五槽构筑，同时加入与敌军状态体系对应的四种自动 Buff。本版本代号为 Voxel Module Forge，仍不是 Steam 发布候选版。

## 体素积木建模

- 玩家三机体使用统一的战机语法：前窄后宽的长轴、白色尖鼻、分段高亮座舱、连续阶梯后掠翼、双垂尾和独立尾焰；壁垒更厚重，脉冲更修长，彗星保持均衡截击机比例。
- 玩家模型朝航线前方，所有敌军底座绕 Y 轴旋转 180° 朝向玩家；武器炮口与推进焰因此位于真正的前后端，不再出现双方机头同向或横向虫形剪影。
- `BoxGeometry` 实体进入平面法线 PBR 批次，发光体素按颜色进入独立不受雾影响的实例批次，辉光外壳整体放大后进入关闭深度写入的后层；没有实体面与透明面共面，旧版闪面被架构性移除。
- 敌军的五个模块拥有独立空间位置与色彩语言；单个构筑能从轮廓上同时辨认移动器、武器挂架、核心防御、AI 天线和载荷罐。
- 精英、屏障、命中、Buff、Debuff、四类弹幕、拾取物、星门、遭遇物和九生态背景复用实例化方块，不引入会因窗口缩放变糊的位图功能图标，也不使用球体、圆环、八面体或锥体替代积木造型。

## Three.js 渲染架构

- Three.js 作为精确版本的生产依赖随 Electron/Windows 包离线分发；HTML 以 ES Module 顺序加载渲染器和游戏，不依赖 CDN 或远程脚本。
- 一个共享 `BoxGeometry` 驱动实体批次；自发光体素按颜色缓存为独立 `InstancedMesh`，避免每帧创建 GPU 几何或为每块积木提交一次 draw call。
- ACES 色调映射、平面法线金属/粗糙度材质、半球/方向/玩家点光源、指数雾、双层星空和 3D 网格共同提供稳定科技光影。
- `scripts/verify-renderer3d.mjs` 明确拒绝 `createShader`、`drawArrays`、手写 buffer 以及 Plane/Sphere/Torus/Octahedron/Cone 几何回退，并检查玩家/敌军相反朝向与 Three.js 后端诊断。

## 五槽敌军工坊

五个槽位各有四种模块，形成 `4 × 4 × 4 × 4 × 4 = 1,024` 个稳定签名：

- 移动：标准、蛇形、突进、漂移，控制基础速度、加速与航迹。
- 武器：脉冲、双联、狙击、环轨，控制射击间隔、弹速、散布与弹幕造型。
- 核心：轻型、装甲、屏障、爆裂，控制耐久、防御和死亡连锁。
- AI：哨兵、猎手、侧袭、先知，分别面向最近、最弱、孤立和前导位置选择目标，并逐级引入转向追踪、预判、侧袭与闪避。
- 载荷：洁净、冰冻、干扰、破译，决定敌弹颜色、体素外挂和命中 Debuff。

第一章前段固定使用 `standard.pulse.light.sentry.clean`，高级 AI 只随精英和章节预算逐步开放，普通敌人的状态载荷到第三章才加入，避免系统扩展重新制造早期难度墙。

## 自动 Buff 与敌军 Debuff

- **军械超频**：8 秒内伤害 +8%、自动射速 +24%，机翼生成双侧方块炮架。
- **纳米花簇**：8 秒内机动 +12%，每 1.1 秒自动修复 0.25，机体周围生成绿色维修微方块。
- **神盾矩阵**：9 秒内自动拦截近身敌弹并把 Debuff 持续时间减半，生成蓝色立方护笼。
- **磁通核心**：7 秒内能量获取 +30%、拾取牵引 +70、共振光链伤害 +12%，生成紫色八方磁通光环。
- **冰冻/干扰/破译**：分别把移动、自动射速和能量获取降低到 82%、84% 和 72%；破译命中额外立即消耗 6 能量。

Buff 由既有拾取物自动赋予，Debuff 由实际敌弹命中触发。神盾拦截、纳米维修、射击、技能、协议与狂潮全部自动运行，玩家仍只控制方向。

## 音频、HUD 与测试面

- Buff 上线使用明亮上行音簇、低频确认和噪声闪光；Debuff 使用独立锯齿脉冲与短噪点，避免与射击、拾取、命中或狂潮混淆。
- 当前 Buff 和 Debuff 会向 8-bit 音序器注入节奏信号；Boss 战仍在生态与航线调式上提高鼓组、低音和高音密度。
- 高清 Canvas HUD 显示每机当前状态，敌军扫描同时显示五个模块名；新增诊断公开 5 个槽、1,024 目录、强制构筑和双机正负状态。
- `qa-voxel&qa-buffs&qa-status=chill&qa-enemy=drift.orbit.barrier.oracle.cryo` 提供不加速玩法时间、抑制事件/Boss 的可复现建模展示面。

## 工程与验证

- 新增 `src/status.js` 统一管理四 Buff、三 Debuff、拾取映射与战斗倍率；`src/expedition.js` 集中管理五槽数据与构筑预算。
- `scripts/verify-status.mjs` 验证定义、双语、自动输入约束、倍率、体素/音频/HUD/诊断接线；`scripts/verify-expedition.mjs` 穷举 1,024 个唯一签名并验证目标模式、状态载荷、确定性和首章安全。
- `npm run verify` 通过：26 份 Markdown、408 个引用键 × 2 种语言、Three.js 实例化体素/稳定深度层/相反朝向/禁用手搓面片检查、4 个 Buff、3 个 Debuff、1,024 种敌军构筑、JavaScript 语法和现有 Roguelike/天赋/协议/狂潮/生态/航线/遭遇系统。
- `npm run smoke:electron` 在隔离真实 Electron/WebGL 会话中确认强制五槽敌型、双机四 Buff、P1 冰冻状态、协议自动触发、方向输入完成信标、狂潮完整结算、接近 60 FPS、2142×1203 HUD 和 0 个应用控制台/CSP 错误。
- 人工检查了无状态干扰的 `spacescraft-airframe-showcase.png` 与完整状态的 `spacescraft-voxel-showcase.png`：白色尖鼻、纵向座舱、连续后掠翼、双尾焰、反向敌机、五槽外挂、Buff/Debuff、彩色 3D 弹幕、体素星球/科技塔、稳定辉光与 0.15.0 页脚均清晰。内置浏览器运行时初始化冲突，因此该路径未列为通过。
