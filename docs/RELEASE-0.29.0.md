# SPACECRAFT 0.29.0 — 棱彩前线 / Prismatic Front

发布日期：2026-09-21

0.29.0 让战斗反馈以克制、可读的像素碎片和破碎冲击波呈现，并将智能芯片敌机提升为会避险、重新交战与真实开火的精英单位。游戏继续保持真实 WebGL 3D、只需方向移动和自动战斗；单人 AI 僚机、双键盘与双手柄支持不变。

## 玩家更新

- 护盾按真实来袭侧显示局部切面和反射碎片，破盾外散、装载内聚；星链、电弧、炮口、命中、拦截与余烬使用不同速度和大小的像素碎片。
- Nova 与爆炸改为世界 XZ 平面上的破碎冲击波，保留真实清弹范围与伤害结算，不再绘制固定范围轮廓或全屏白闪。
- 普通敌机和远端节点在开火前出现短促喷溅；追踪弹在制导结束后收暗尾迹；种雷与爆破种用弹体热芯和临爆脉动表达引信。激光危险主体、宽度和冲刺预警不变。
- 智能芯片敌机会完成闪避或残血防御后撤，再回到可达射程稳定开火。背部芯片和双翼灯条编码待机、攻击、闪避和防御后撤，并提供简体中文与英文扫描说明。

## 智能精英参数

同型芯片机获得血量 +25%、最大移速 +18%、转速/角加速度 +30%、推进加速度 +35% 和制动 +25%。三章出现概率为 14%/22%/28%，在场上限为 2/3/4；首章前 25% 和成长缓冲仍不生成。弹速、伤害、射击冷却、预警时长和全场攻击/弹量预算不变。

## 平台与附件

- Windows 10/11 x64：安装器和完整免安装 ZIP。
- macOS：Apple Silicon arm64 DMG。
- 每个平台附带 SHA-256 清单。Windows 未代码签名，macOS 未 Apple 公证；首次启动可能显示系统安全提示。
- 网页版部署到 <https://quater782.github.io/spacescraft/>，使用同一标签源码，进度保存在当前浏览器，不提供云同步或网络联机。

## 验证边界

本地 `npm run verify`、文档链接和静态检查已通过。真实 Electron/WebGL 特效专项覆盖护盾、星链过载、激光、低画质和正常开局：108 帧动态画面，低档 96 粒子、零丢弃，20.18 秒双机 7/7 HP、60 FPS、零页面错误。智能精英专项覆盖 16 船体、三章 Boss、四种芯片机持续来弹和 210.22 秒正常速度双 AI 样本：双机 7/7 HP、零倒地、98 击杀、60 FPS。

标签工作流会在 GitHub 托管的 Windows x64 与 macOS arm64 上构建，并从包内动态检查菜单、机库、设置、语言切换、WebGL 与快速自动战斗；网页工作流会从标签产物执行同类网页冒烟后部署。声音专项未重验，因为生产声音未改；完整首章、真人本地双人/双手柄、Windows 实机、多显卡矩阵及历史完整首章难度缺口仍未完成。
