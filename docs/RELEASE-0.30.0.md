# SPACECRAFT 0.30.0 — 协同战线 / Cooperative Front

发布日期：2026-09-25

0.30.0 聚焦更清楚的双机协作与章节终战。友军会按战况重新评估救援、任务、补给、集火和闪避；三章 Boss 有更鲜明的战斗轮廓与连续攻击；护盾受击反馈现在直接沿外缘传播，多发冲击可以同时留下方向和颜色。游戏仍是实时 WebGL 3D、只需方向移动、自动战斗的合作射击游戏。

## 玩家更新

- 友军 AI 根据当前目标、队友状态、敌方威胁、补给和任务期限选择行动。救援范围内会保持协作，危险解除后继续当前目标；单人和双 AI 战斗共用正式决策逻辑。
- 调整第一章学习压力与后续构筑需求，补齐敌军移动预测、追踪弹和活动激光的威胁评估。主炮锁定的方向和移动承诺更一致，芯片激光有清楚的三秒瞄准过程。
- POM、BOLT、NOX 重建为三种不同的章节首领；战场保留既有敌人和危险，Boss 招式按阶段连续齐射，转阶段逐步呈现新器官，并提供可辨识的核心暴露窗口。删除两侧装饰，让攻击预警更易阅读。
- 护盾保留矩形像素外缘、亮芯和柔和辉光。实际命中会沿外缘产生不同幅度的压缩、回弹和切向传播；同帧的多次冲击分别叠加，颜色沿对应的受击波移动。
- 开场在真实 WebGL 画面准备期间展示双语 Logo 和加载状态，首帧完成后淡出。减少动态效果设置继续生效。

## 技术与兼容

没有新增运行时依赖或存档字段。玩家控制仍为移动方向；自动射击、能量技能、星链和近距离救援保持自动触发。单人 AI 僚机、本地双人键盘和双手柄入口继续保留。

桌面发行链在 Windows x64 和 Apple Silicon macOS arm64 上构建并从打包应用执行动态启动检查。Windows 安装器未代码签名，macOS DMG 未公证。Windows 免安装 ZIP 请完整解压后运行。

## 验证边界

`npm run verify` 覆盖文档、资源闭包、本地化、关键战斗/成长模块及生产依赖审计。护盾多点碰撞与画廊、正常速度首章开局、Boss 三章独立遭遇、成长平衡和友军决策均有专项记录；真实 Electron/WebGL 画面与关键帧已检查。三章 Boss 样本证明受控 AI 构筑可通关，不等同真人胜率。

完整自然连续三章的真人体验、真人双人/双手柄、不同 Windows PC 和主观音频验收仍需后续覆盖。桌面包与网页构建由 v0.30.0 GitHub Actions 工作流产出；网页部署地址为 <https://quater782.github.io/spacescraft/>。
