# 0.8.0 发行说明：Roguelike 星航构筑

0.8.0 的 Major 主题是把三章射击战役升级为具有局内决策与可复现构筑的 Roguelike 航行。两名驾驶员继续只控制移动；自动火力、技能与救援规则没有改变。每章 Boss 后新增一次共享三选一，让同一套自动战斗可以形成明显不同的火力、机动和系统组合。本版本代号为 Roguelike Alpha，仍不是 Steam 发布候选版。

## 玩家体验

- 第一章和第二章 Boss 净化后各进行一次共享三选一，左右选择、上下确认；P1 使用 WASD，P2 使用方向键，手柄使用摇杆。
- 15 项升级分为武装、机动、系统三类，并以普通、稀有、传奇三档权重出现。候选默认保证每类一项，满级项目自动退出池。
- 武装路线包括射速、伤害/弹速、永久齐射、穿透、自动僚机与击破连锁；机动路线包括速度、响应与相位机壳；系统路线包括循环护盾、维修、能量、超新星、双子光链与拾取牵引。
- 两架战机共享选择并同步获得效果；升级可叠层，当前构筑以矢量 SVG 图标显示在战斗边缘和任务报告。
- 构筑页与任务报告显示航行种子。开发环境可用 `?seed=<整数>` 复现候选、敌人、弹幕与掉落序列。

## 工程与可靠性

- 新增 `src/roguelike.js` 作为可独立验证的规则模块，统一拥有升级定义、Xorshift32 随机源、候选权重、满级过滤与玩家效果。
- 玩法 RNG 与星空、粒子、随机音色的表现 RNG 隔离；调整画面反馈不会改变后续敌人或选牌。
- 快速 QA 默认自动选择升级，可追加 `qa-draft` 停在构筑页进行方向操作检查。
- `#game` 增加 `data-run-seed`、`data-upgrade-count`、`data-upgrades` 与 `data-draft-options`，用于稳定读取构筑状态。
- 新增 `scripts/verify-roguelike.mjs`，覆盖 15 项效果、唯一 ID、合法类别/稀有度、同种子复现、异种子分流、满级过滤、候选去重、早期权重与叠层。
- 本轮验证覆盖 19 份 Markdown、258 个引用键 × 2 种语言、JavaScript 语法、构筑规则测试和正式依赖审计；`npm audit --omit=dev` 为 0 个漏洞。

## 已知验证缺口

本轮本地浏览器自动化访问被宿主安全策略拒绝，因此没有把章节间构筑的可见 UI、方向键交互或完整三章运行记为已通过。代码级规则、静态资源、双语、包内内容和归档完整性均已验证；正式候选版仍需在浏览器及 Windows 10/11 实机完成单人/双人、双语言、手柄、正常时长三章和长时间稳定性回归。
