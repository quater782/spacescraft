# 3D 像素视觉方向

## 2026-09-25：先构图，再细节

当前场景不再使用统一的“行星 + 断环 + 碎片”套餐。九个星域分别组织方舟、晶冠、行星、轨道站、感应环、日蚀、断碑与裂环；一个主景决定画面方向，星空与星云提供纵深。中央战斗区域保留负空间，主景向边缘偏置，像素颗粒来自几何阶梯和离散材质。

方舟采用两片收尖壳体围合琥珀凹槽，移除白亮的大块核心；熔炉以完整弧形语言组织舱段与太阳能板，不再叠加另一座大型构筑物。星云采用一次生成的不规则低对比纹理，减少圆形散景颗粒。低画质保留主轮廓，只减少星空/星云数量；不提高全局 Bloom。

远景动态附着于原有主景：检修窗、内嵌灯带、慢转机械、行星分层云带与沿结构传递的微光。主结构具有可辨认的转动/偏航，运行灯按 7–16 秒节奏传递；星云漂移和呼吸，补足远处空间；不恢复无交互漂浮碎块，不做急促闪烁。

所有背景设置及其叠加来源集中于 `src/scene/`。详细构图、文件职责、遗留入口清理和验证方法见[场景系统与美术配置](./SCENE-SYSTEM.md)。本节替代本轮早期“九生态均加入天体及轨道残骸”的方案；敌我机体细节和粒子光保留。

## 2026-09-25：沿原有外缘传导与多点叠加

本节替代下方历史中的椭球波圈、同步盘旋生成与整圈受击闪光。只绘制原有的一圈矩形粒子，不再从命中点生成扩张椭圆或额外轨道。生成保留每颗粒子的独立延迟、内外起点和偏转路径；落位后直接成为常态粒子。低档 30 颗、其他档 48 颗，亮芯细小，边缘允许柔和 glow，不能放大成实心板块。

每次接触向周期外缘注入一对有正负相位的波包：先局部内凹、再回弹，波动向两侧传播；同种护盾使用相同传播速度，伤害改变幅度和波包宽度。1/2/4 点采用非线性幅度区分，重击应显著深于轻击。斜擦按法向入射程度减少压缩，并增加切向剪切和顺擦方向权重。接触火花与反射飞屑保持局部，颜色跟随对应的波动进入原有粒子。

同时或连续命中分别保留独立事件；有符号的径向与切向位移先相加，再平滑限制到安全范围，避免最后一发覆盖前一发，也避免将所有冲击取绝对值后只能膨胀。颜色按各自响应强度混合，与处理顺序无关。径向限幅 0.57–1.43，常态不会全盾染色。破盾仍从受击附近错时松脱。此模型仅模拟视觉上的弹性反馈，不改变碰撞边界或反射真实子弹。

每机保留最多 12 个、持续 0.8 秒的接触，随固定步 dt 推进并回收。实际扣伤与保护时间内接触均使用来弹伤害相对总容量确定表现强度；保护时间内不重复扣伤、计数、充能或音效。完全破盾后的重建清掉旧接触。诊断：`data-shield-field-motion="perimeter-signed-wave-superposition"`、`#game` 的 `data-player-shield-impact-count`。

2026-09-25 Boss 战场净空：按用户要求删除全部 Boss 专属两侧花瓣、磁轨门柱和裂冠装饰，取代下方历史记录中的边缘建筑渐入；实际激光预警保留。

## 2026-09-25：发光矩形护盾与差异化冲击

本轮以 0.28.0 的发光护盾为底，恢复常态 30/48 颗（低档/其他档）、重组 30/54 颗的细小能量粒子与包覆感。矩形指亮芯的四个直角，不把粒子放大成实心板块；保留低亮柔和 glow、大小错落与逆向漂移。光晕采用方形距离衰减，碎屑保留双色矩形明暗。盾面仍是世界空间中的真实 3D 椭球，不改碰撞。

实际吸收伤害（视觉最高按 5 点封顶）控制冲击尺寸、碎片数量、波前长度与传播距离；轻击短而局部，重击更宽更远。正撞向两侧传播，斜擦强化切向侧、压低逆向侧，飞屑沿真实反射甩出。破盾整体外散，来袭侧额外扩散，斜擦保留切向偏移。受击时短暂揭示整个包覆边界，来袭侧最亮，不增加持续实线或指示圈。

接触点、传播波头和少量碎片继承攻击颜色；有异常载荷时优先读取 `payloadColor`，激光实际命中也携带该元数据。色彩只停留在局部冲击，余片冷却为蓝青，重组仍用蓝青。炮口、星链、电弧和命中共用矩形材质，弹道与脉冲的主要碎屑用普通透明混合；护盾恢复原来的加法能量材质。Nova 波面仍保留原有渐淡破碎和真实范围，不恢复固定圈。

2026-09-24 连续蜕变补充：阶段新增器官按 1.4 秒平滑生长，已有器官保留；花瓣/肩塔/双镰随暴露窗口在 0.2 秒内打开、最后 0.3 秒收拢，避免瞬间跳形。首章上行三角波、次章低音机械拍、终章不协和回应区分转阶段，降低噪声，不重置音乐时钟。受控半展开与全展开截图覆盖三章（终章低画质），不改变碰撞轮廓。

2026-09-24 Boss 演出更新：取消登场/阶段镜头推拉与中央遮挡；三章分别使用花瓣尖端逐个蓄亮、肩塔电容分段充能、双镰左右回应，取代共享光环与三根发光炮管。核心暴露有本体展开与低亮刻度；边缘花瓣/磁轨/裂冠在原生态内渐入，滚动速度不再随蓄力跳变。规则和验收见 [Boss 章节设计](./BOSS-ENCOUNTERS.md)。

## 2026-09-19 — 开发历史（已合入 0.29.0）：战斗反馈材质与节奏统一

Major 主题：把脉冲的克制亮度和形状层次推广到护盾、星链、电弧、炮口、命中、拦截与余烬。新增普通透明混合的双色像素碎片材质，切角轮廓与明暗面提供细节；只有短促接触点继续使用小尺寸辉光。碎片和亮点共用 4096 总预算，各自使用复用 GPU 批次。

护盾常态密度降低，受击只强调真实来袭侧的局部切面与反射碎片，删除整圈亮闪；破盾外散、装载向内聚合保持不同运动。星链变为间隔流动的能量簇和小端点，过载翼流改为彩色碎片。电弧增加九段折点、短支叉和分帧变化；炮口/命中/拦截采用大小与速度不等的碎片。基础星链脉冲与 Nova 回响复用破碎波材质。激光危险主体/宽度及冲刺预警不变，仅把装饰火花改为较暗碎片、缩小喷口光晕。

无战斗参数、声音、存档、文案、版本或依赖变化。新增 `data-effect-flecks` 与 `data-combat-material-style="faceted-chips-local-hotspots"` 诊断，粒子总数仍包含两种材质。保留工作区既有修改，未打包。


## 2026-09-19 — 开发历史（已合入 0.29.0）：脉冲形状、明暗与消散重做

Major 主题：用有层次的能量片与碎屑表现冲击，移除三层等距发光方块堆出的灯带。Nova/爆炸主波改为世界 XZ 平面上的程序化像素片，径向宽度、切面亮度、次级拖片、像素缺口和消散顺序均有变化。主波采用普通透明混合，双机重叠不再加法漂白；少量亮边与 8/14 颗错峰碎屑承担细节。波前保持真实效果半径内运动，范围表达通过扩散和破碎完成，不恢复固定指示圈。

移除 Nova 旧 64 颗径向装饰碎片和全屏白闪，震动从 0.45 降为 0.18；触发、清弹半径、伤害、冷却与声音不变。新增 56 波复用缓冲，`data-effect-waves` 记录实际波数；低档保留主形，只减少辅助碎屑。保留敌弹蓄亮、激光/冲刺预警和既有工作区修改，未改版本或打包。

### 参考与本轮取舍

参考 Riot 官方[特效制作教育](https://www.riotgames.com/en/artedu/visual-effects)与[特效更新流程](https://www.leagueoflegends.com/en-us/news/dev/dev-behind-the-scenes-of-vfx-updates/)：克制装饰和亮度，准确传达玩法，并在实际游戏上下文中检查效果。此次具体取舍是局部短冲击、稀疏亮点、彩色中间调、破碎消散；不照搬 League 的纹理或角色美术。此前三层辉光环缺乏明暗和时间层次，本节替代其视觉实现。

主波是程序化透明材质，颜色不超过白色且不带模糊光晕；32 个角度区段调节厚度、亮部与拖片，世界坐标像素网格提供稳定阶梯边缘。细节噪声只取静态位置种子，消散读取模拟事件年龄，暂停时冻结。主形前快后慢外推，寿命后段逐渐挖空；少量碎屑在内部错峰散开。没有固定边界、不引入全局 Bloom 或新贴图。


## 2026-09-19 — 开发历史（已合入 0.29.0）：渐淡像素冲击波

Nova 和爆炸只用三层有厚度、边缘渐淡的像素粒子波表现冲击范围，去掉固定边界和细线。波前在效果寿命的前 48% 抵达本次实际范围，随后消散；Nova 为 0.85 秒，爆炸仍为 0.46 秒。双机 Nova 读取各自释放位置和真实清弹半径；不是持续护盾，也不把更大的敌机伤害半径当作清弹范围。

按用户修正，敌方种雷/爆破弹也删除倒计时圈，改为弹体热芯随引信蓄亮、临爆脉动；激光和冲刺保留攻击预警。低画质减少波前粒子，复用现有 GPU 缓冲，无新纹理、依赖或全屏后处理，不改变引信、伤害、清弹结算或战斗数值。诊断为 `data-nova-range-style="feathered-pixel-shockwave"` 与 `data-fuse-timer-style="body-heat-no-ring"`。本节替代下方历史闭合范围圈的视觉设计；未打包。

普通敌机开火阶段前 0.18 秒从承诺炮口或真实远端节点喷出一次暖色碎粒，激光沿用已有点火、Boss 不重复叠加。追踪弹在 `homingDuration` 结束时从亮短尾焰切换为更暗、更短的滑行余焰。普通敌弹只附带两颗低亮尾粒，弹墙/交叉墙保留原剪影；Boss 弹增加局部热芯，载荷色仍保留在弹头内部。

种雷/爆破种读取实际 `age/triggerAge`，热芯随引信增强，4/8 个边界亮点分别服务低档/其他画质；边界位置严格读取 `blastRadius`，没有向外飘出的假弹体。旧轮廓继续保持可见。所有动画不增加计时器或玩法随机调用，复用点缓冲。`#scene` 诊断新增 `data-hostile-particle-style="muzzle-burst-tracking-fuse-ticks"`。

## 2026-09-19：像素粒子技能与弹道

弹头保留各弹种真实 3D 像素剪影；尾迹改为 2–3 颗递减亮度与尺寸的短粒子，不用长条光柱遮盖敌弹。普通友弹也有短尾迹，满阶侧翼点缀保持独立色组；敌方追踪与针弹仅替换已有尾迹，普通危险弹不额外铺光。

炮口和命中采用短促暖白闪光、不同径向速度的色彩碎粒、平方衰减余韵；位置按 0.035 世界单位量化，保留方形亮芯。链式电弧保留细中心线并增加稀疏像素亮点。爆破外轮廓继续对应实际瞬时伤害范围，装饰碎粒只在内部扩散。共享 Nova 从真实释放位置生成 0.65 秒粒子波，按净空半径向外展开，青/珊瑚色区分双机；波前仅是释放动画，不延迟清弹判定，也不表示持续护盾。

通用碎片继续由模拟更新位置；表现层增加局部辉光、短余烬与末段冷却。所有动画读取现有事件年龄/粒子寿命，无额外随机调用；GPU 点缓冲仍为 4096 上限，低画质减少尾迹和波前粒子。`#scene` 新增 `data-particle-style="stepped-pixel-wakes-burst-cooling"`，旧诊断保持兼容。没有新贴图、依赖或全屏后处理。

## 2026-09-13：敌机姿态与动作来源

敌机船身 yaw 来自逻辑 heading 的世界坐标映射，机翼倾斜和俯仰读取受限转向/加速度；悬浮船体以侧推器解释横移，可转炮座显示轴承。机炮、激光和冲撞都要先对准；普通蓄力只显示炮口热芯，删除全机周期光环和向机鼻汇聚的粒子。冲撞红线两侧增加接触宽度边界，尾迹只来自真实路程；弹墙/夹击以提前可见的固定远端发射器解释跨屏来源。Boss 也缓慢转体、稳炮后开火，多束激光显示各自炮口。共享实例和粒子缓存继续复用，不新增位图或全屏特效。


本规范是场景、玩家、敌军、模组、弹体和后处理的共同美术约束。目标不是把低分辨率画面放大，而是在真实 WebGL 3D、透视与光照中使用清楚的大颗粒几何，得到可读、克制、会发光的立体像素风。

## 2026-09-13：入射几何、吸收伤害与激光属性

本轮 Major 主题为战斗数据驱动的能量反馈。护盾保留命中相对位置和相对入射方向，在机体局部坐标中求轨迹与可见椭球盾面的进入交点、法线和反射方向；正撞集中扩散，斜擦沿切向偏移亮弧并反射飞屑。宽光束或碰撞容差导致轨迹未穿过可见椭球时，以最近点投影回盾面。该求交只负责表现，不改变既有命中判定。

粒径、碎片数、辉光与命中声音力度跟随该次实际吸收伤害，最高按 5 点伤害封顶视觉强度，音量最高 1.75 倍。4 点伤害被 1 点护盾吸收时，护盾按 1 点触发破碎，余下 3 点仍交给机体反馈，避免把溢出伤害重复解释成护盾吸收。

激光外层宽度直接来自 `beam.width`；伤害提高亮芯占比、辉光和开火碎屑强度。普通/精英/首领身份调整流动脉动，扫射读取实际攻击模式与色彩，异常载荷读取真实 debuff/payloadColor。普通突刺当前为伤害 2、半宽 5.4；精英为伤害 3、半宽 7；扫射半宽 4.6，以上均沿用玩法数据。没有增宽碰撞或提高敌人伤害。开火后的前 0.3 秒内，喷口碎屑沿射线前向扇形喷出、衰减，不循环冒充新的开火瞬间；外层色带减淡，像素亮芯和局部辉光保持可读。

## 2026-09-12：护盾声光状态与连续像素激光

Major 主题为护盾状态辨识与激光轮廓。受击显示 0.48 秒方向亮弧、短促接触闪光和盾边冲击波；破盾显示 0.8 秒全周碎裂、不同速度的外散碎片。回复电荷后显示 0.72 秒向内盘旋聚合，随后回到常态粒子场；无敌帧、伤害和回复间隔没有延长。局部高亮优先让来袭侧可读，不提高全局 Bloom。

发射后的激光移除两条外围红线与均匀亮簇，改用世界 XZ 平面上的连续能量带：暖白亮芯、橙红阶梯色带、沿轴向推进的像素亮度变化，以及少量边缘余烬。亮色带宽度对应原碰撞半径，外层是衰减辉光；发射前瞄准仍用闪烁红线。端部短距离渐隐，保留真正起终点，不使用长方体或圆柱主干。

三种声音分别采用低频敲击＋高频电击、降调碎裂＋噪声、上升锁定音阶＋余响；继续通过原有音效总线和静音/音量设置。补盾反馈只在电荷确实增加时触发，覆盖自然回复、拾取及单人分享、研究、升级、救援和航线/遭遇奖励；满盾补给不会播放装载声。

本节替代下方历史条目中激光外围边界细线与旧护盾计时描述。

## 2026-09-11：护盾与激光的粒径、动态和局部辉光

本轮 Major 主题为能量粒子层次。护盾常态使用大小错落、不同周期显隐、反向漂移的椭球粒子；受击有短促接触闪光、沿来袭侧向两边传播的波前，以及会旋转、外散、缩小和冷却的碎片。破盾提高扩散距离。少量大亮芯承担强反馈，中等碎片解释运动，细尘补充余韵，避免等尺寸光点组成一圈白边。

激光保留实际中心线与宽度提示，增加不等速的热粒、带递减尾部的快速亮簇、偏离热芯后衰减的红色余烬和发射口火花。亮簇疏密变化，暖色亮芯与红色小粒分工，避免均匀珠串。所有动画读取模拟时间或原有受击/光束计时器，不消费玩法随机数。

粒子单独传入辉光范围、长宽比与旋转角；硬边像素亮芯外包局部柔光，亮芯轮廓带离散阶梯。局部辉光在低画质仍可见，未提高全屏 Bloom；没有更换船体与弹头的像素材质。仍使用单批次、4096 点上限和深度测试。

## 2026-09-11：像素粒子战斗反馈

冲刺、激光、护盾和星链统一使用方形亮芯、分级辉光与稀疏粒子；实体机体和像素弹头保持原风格。新增 `src/pixel-effects.js` 以一个可复用 GPU 点缓冲绘制最多 4096 颗世界坐标粒子；低档减少密度，方向预警与判定中心线继续可见。

- 红线预警：激光沿真实射线，冲刺沿锁定终点；随蓄力进度从约 1.1 Hz 增至 7.1 Hz，按频率积分连续闪烁，暗相仍保留细线。口器用向内聚集的红色粒子取代旋转方块与粗环。
- 冲刺：0.38 秒短尾迹取自敌人实际位置历史，最多 28 个采样；赤红粒子沿经过路径冷却、外散，不把目标方向的推测直线冒充已走轨迹。
- 激光：原生细线热芯与边界提供连续判定提示，红色/暖白粒子向前流动，发射口有短促火花。移除圆柱主干、横杆能量包和球形端帽；横向偏移先按逻辑宽度计算再映射到世界坐标。
- 护盾：常态为稀疏椭球粒子场，受击时在实际来袭侧形成局部亮弧与散射，破盾碎粒向外扩散。弹体、光束、爆炸和机体/陨石接触传入源位置；源与玩家重合时用反向速度，无方向信息时用均匀反馈。
- 星链：细中心线保持真实连接段，青色粒子从两端向中心汇聚；充能越高流速越快，过载变为紫色加速流，冷却时减弱。密度随连接长度控制，贴近时不挤成光团。共享拦截节点亮灭跟随剩余数量，拦截点以局部粒子散射反馈。

诊断：`data-combat-effects="pixel-sparks-directional-shields-flow-link"`、`data-effect-particles`、`data-effect-dropped`。旧诊断值为兼容保留；本节替代下方历史条目中的实体护壳、圆截面激光和冲刺箭头描述。

## 渲染语法

- WebGL 使用原生 CSS 像素采样；高画质设备像素比上限为 1.5，平衡档为 1，低档为 0.72。离屏合成使用 SMAA，避免 EffectComposer 绕开默认帧缓冲多重采样后重新出现锯齿。
- 原有体素主体保持 0.12 最小边长和 0.04 步长；新增实体细节尺寸按 0.04、局部位置按 0.02 量化。座舱和眼核由十九格阶梯体组成，实体环为无倒角阶梯挤出。曲面燃烧和渲染线不套用实体粒度下限。
- 所有实体体素都有同色自发光下限，并进入 3.8% 不透明度的略大加法 Glow 壳；它只让每块像素边缘“带电”，不能把固有色冲成白色。
- 旧 HDR 体素批次只用于功能光源；新座舱和眼核主要使用深色三阶色带，尾焰使用独立透明曲面。Unreal Bloom 使用五级模糊链、1.03 亮度阈值、0.30 强度和 0.10 半径，显示白以下的陶瓷装甲、环境岩体与普通甲壳不得触发 Bloom。
- 实体统一使用三阶 Toon；陶瓷、金属、甲壳和座舱分别配置明暗色带，最近邻采样保持色阶边界。禁用实体 PBR 高光、清漆和圆润倒角，有限色阶承担质感区分。
- 屏幕边缘保持抗锯齿，实体轮廓保留阶梯，燃烧允许曲面；“像素化”不等于关闭抗锯齿。

稳定诊断：`data-pixel-grammar="coarse-emissive-012"`、`data-energy-bloom="unreal-selective-5mip"`、`data-edge-aa="native-smaa"`、`data-ring-grammar="continuous-segmented-arcs"`。

## 深空构图

- 画面至少 55% 保持深色负空间；星点分为三层视差，不能铺成均匀噪声。
- 禁止连续地板、导航网格、左右成对护栏、贯穿画面的门架和周期性透视线；任何透视地面都会重新制造隧道感。
- 行星、奇点、遗迹和异象放在偏轴远景，不占据中央射击通道；同屏大型地标原则上只有一个。
- 生态件使用低饱和海军蓝、灰紫和冷岩色。生态原色只作为局部边缘或核心，不与敌军争夺饱和度。

## 阵营识别

### 玩家

- 70% 灰蓝/暖灰哑光陶瓷阶梯面，20% 玩家识别色，10% 深色座舱和功能核心；陶瓷值域必须低于 Bloom 阈值，不能在实战中冲成粉白。
- P1 使用深蓝与青色；P2 使用酒红与珊瑚红。两者共享人类风筝形语法：长鼻、薄翼、清楚尾焰。
- 模组嵌入背脊、翼根或护盾肩，不悬浮，不给主体增加第三套装饰色；以线圈、发生器、维修舱、天线等实体结构区分。四种模组必须从轮廓位置而非碎块数量辨认。
- 机体追求少而完整的大块面。单侧翼与尾翼不得靠多层重复小方块堆厚。
- 护盾使用稀疏像素粒子场，吸收时在来袭侧局部亮起，耗尽时向外碎散；耐久 ≤60% 出现焦痕和烟迹、≤30% 增加灼红裂痕，维修后随实际耐久恢复；共振光链使用低亮细中心线与青色汇聚粒子，过载呈紫色加速粒子流，不得盖过舰体。

### 敌军

- 70% 深紫甲壳，20% 血红结构，10% 酸性黄绿眼核/武器尖端。
- 使用新月、甲壳、分叉颚、触须、眼核和不对称重心；禁止复用玩家机鼻、机翼和尾翼构造器。
- 酸性颜色只能出现在眼睛、尖端、核心和弹体载荷，不得铺满大翼面。

## 弹体

- 玩家弹头统一采用逐格设计、带厚度的三维像素图形：普通弹为方头阶梯短矢，相位弹为分叉贯穿刃，僚机追踪弹为翼状短镖，重弹为宽肩弹。P1 青绿、P2 珊瑚，相位青蓝、追踪紫、重弹琥珀；不使用圆润眼核网格、白亮光珠或圆管拖尾。
- 敌弹使用珊瑚红像素主体、深紫切口和嵌入式亮核。普通种刺、双颚、针枪、旋镰、弯刃、横向弹墙、叉形追踪弹、种雷、爆破种与三种 Boss 弹分别有独立轮廓；载荷只替换内部核心色（冰冻青、干扰粉紫、破甲橙），不添加会误导碰撞的游离外核。高对比模式统一黄体、深红边与白芯。
- 种雷和爆破种在实际引信进度 65% 后切换开裂像素帧；追踪弹在实际制导窗口结束后收翼并熄掉感知亮核；旋镰/种雷/虚空弹仅将装饰旋转采样为 12 帧，位置、速度与碰撞继续读取真实模拟。
- `src/projectile-art.js` 将每种轮廓和三色板一次合并成共享三维网格；每枚弹仅写入一个实例，单组合容量 512。顶面、侧面和底面使用离散色阶，弹头不使用 Bloom 壳；低画质也保留全部识别细节。特殊弹的短拖迹为低亮原生线，普通弹依靠像素尾端表达方向。
- 普通射击不得用一条线连接敌机和玩家；口器蓄力、局部警戒环和弹体朝向已经足够。激光预警沿完整实际射线，冲刺预警沿锁定终点，以细红线和加速闪烁表达启动时机，不能在玩家处终止成牵引绳，也不能靠加粗或过曝冒充清晰度。实体激光必须沿真实伤害段显示双侧能量边缘、连续热芯与沿方向运动的能量包；有限追踪弹使用偏转尾迹，范围爆破种以对应实际半径的断续危险环区分飞行与引爆阶段，撞角单位以锁定红线和真实路径的粒子尾迹表达冲锋。
- 死亡机能沿原机体器官语言发射扇片、交叉、种荚或爆震，精英只放大主体和局部能量强度，不允许用全身白光代替危险等级。
- 弹体要比环境更饱和，但不能用贯穿画面的长光轨制造伪隧道。

稳定诊断：`data-projectile-readability="dim-friendly-hot-hostile"`、`data-bullet-grammar="locked-safe-lanes-curves-mines-lasers-seekers-blasts"`、`data-projectile-art="extruded-pixel-stamps"`、`data-projectile-batches`、`data-projectile-dropped`。

## 实机验收

1. `npm run smoke:models`：同屏检查三架玩家与十六类敌军的剪影、色组、陶瓷/能量材质分离与表面器官模块归属。
2. `npm run smoke:biomes`：逐一检查九生态是否能仅凭巨型剪影辨认，中心 55% 是否留白，是否存在远景/中景/星云视差与连续分段曲线，同时排除连续地板、护栏或屏幕中心门架。
3. `npm run smoke:anomalies`：逐一检查九异象是否为偏轴局部天象，且第一章正常速度仍可读、可躲避。
4. `npm run smoke:arsenal`：分别检查真实激光、追踪、爆破、死亡机能、精英与实体撞击的视觉判定一致性。
5. `npm run smoke:electron`：检查真实自动战斗中的敌我弹体、近景机体、选择性 Bloom、SMAA、帧率和控制台。
6. `npm run smoke:projectiles`：20 个敌我弹体/状态样本、真实尺寸/2.8 倍细节图、高对比/低画质、192 枚渲染密度夹具以及正常首章 20 秒；放大图和密度夹具不代表正式弹体大小或自然弹量。
7. `npm run verify`：完成静态结构、本地化、渲染契约和依赖验证。
