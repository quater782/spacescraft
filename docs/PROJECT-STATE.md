## 已建立能力

- Three.js 0.185.1 WebGL2 渲染；共享 `BoxGeometry` 通过按颜色缓存的 Toon 实体、HDR 能量件和轻辉光三类实例批次绘制，没有手写面片或光滑实体原语。体素边长至少 0.12 世界单位并按 0.04 量化，每块实体都有自发光下限和 3.8% 同色 Glow 壳。
- 三种玩家机体使用灰蓝/暖灰哑光陶瓷连续面、青蓝/珊瑚玩家色和深色座舱，保持分段锥形长鼻、四段薄翼与清楚尾焰；四类模组压入背脊或翼根，陶瓷、座舱和引擎材质严格分离。护盾改为四片贴翼表面板，不再用悬浮白点遮挡机体。七类敌军使用可读深紫甲壳、血红结构、少量酸性眼核与针刺/甲虫/星镰/水母/双枪/母巢/新月剪影；五维模块改写表面脉络、尾器官、口器、甲壳缝和眼阵，绕 Y 轴 180° 面向玩家。
- 三阶 `MeshToonMaterial`、ACES 色调映射、半球/方向/克制双机点光源、指数雾和三层星空提供稳定科技光影；EffectComposer 使用 Render → 五级 Unreal Bloom → SMAA → Output，1.03 阈值只让 HDR 能量器官发光，陶瓷和环境不泛白。像素感由粗颗粒几何承担，不用最近邻整屏拉伸制造锯齿。
- 九个星域改为开放深空构图：连续地板、导航网格、成对护栏和常驻门架全部移除；每区以一个巨型身份剪影、一组中景生态、两层 3D 加色星云尘带和稀疏航标形成不对称纵深，中央 55% 保持战斗负空间。背景生态限制在 -48 至 -18 世界深度带，不再周期性穿入玩家层。圆环、彗尾、极光、闪电、胞膜和枝条使用连续分段曲线，不再使用方点环。
- 九种活体星域异象按种子一局恰好遍历一次，接入战斗、资源、得分、HUD、结算与 Web Audio；渲染表现为偏轴局部天象，不形成左右对称跑道。
- 玩家普通弹使用低亮玩家色短矢，不再以白芯连成两条发光轨道；相位、追踪和重弹保留白芯。敌弹使用高饱和珊瑚红、紫色倒刺和少量载荷核；只有狙击/长枪职责保留长轴。
- 三章 570/600/630 秒基础航行合计 1,800 秒；每章三个递进战区、九个编队事件和一场三阶段 Boss，完整一局共九战区、27 次编队事件。
- 单人 AI 僚机与本地双人；玩家仅控制方向，射击、技能、共振与救援自动运行。
- 第一章难度保护、敌人并发上限、较慢敌弹、较长受击无敌与可读性选项。
- 五级自适应威胁矩阵持续读取章节、战区、进度、合约、连击、击破动量、狂潮、共振、耐久、倒地与近期受击；缓冲至极限同步驱动普通敌军增援/弹幕/开火/耐久/航速/精度和得分。1.25 秒迟滞、单级步进、首章前段封顶、残血封顶与倒地强制缓冲避免不可读的难度尖峰。
- Web Audio 多轨 8-bit 配乐和分层音效；音乐/音效可独立调节。
- 三机体、四模组、三合约、星尘经济、八枚勋章与 v5 本地存档迁移。
- 完整中英双语目录与自动缺键检查。
- 15 项局内升级、六次章中与两次章间共享三选一、方向确认、三档稀有度、构筑摘要和可复现 run seed。
- 7 种两件套遗物协议；首次组件会让后续构筑确定性提供配套候选，并驱动高速齐射、屏障穿越、追踪蜂群、连锁电弧、护盾新星、拾取晶弹和共振强化。
- 9 种确定性星域生态；每章三选一，驱动 WebGL 光色、3D 地标、敌军节奏、敌型偏好和 8-bit 音乐 BPM/调式。
- 每章开场三座实体 3D 星门与 7 种确定性航线协议；方向汇合自动确认，风险/奖励驱动敌军构筑、战斗参数、得分和音乐，单人 AI 自动跟随 P1。
- 五类模块化动态遭遇；每章四个、每局十二个种子目标驱动信标同步、星骸回收、移动护航、陨星生存或裂隙攻坚，并拥有 3D 实体、共享奖励、失败回退和自适应音乐。
- 三分支九节点恒星天赋网格；星尘永久点亮机动、自动武装与双子共振效果，含前置依赖、v5 存档迁移和实际玩家参数接线。
- 全自动星链狂潮；双机编队与六类战斗事件充能，满槽后强化自动火力/光链/拾取/得分，光链消弹、击破延时、3D 轨道能量环、动态 8-bit 编曲与任务报告均已接线。
- 七个有机船体家族与推进、武器、核心、AI、载荷各四种模块形成 7,168 种完整敌军构筑；模块直接改变机头、翼根、核心舱、后翼与发动机轮廓，并驱动四类 3D 弹幕、目标/预判/侧袭/闪避、屏障/爆裂与三种 Debuff。
- 三章 Boss 分别使用六瓣放射母巢、纵向熔炉脊柱/肩塔和中央裂隙双镰冠三套独立构造器；第二/三阶段会长出大型主体器官，三章弹体分别为花瓣、雷枪与旋转棱体。中性画廊和动态 telegraph 分开取证，避免蓄力泛光遮住本体差异。
- 三章 Boss 共 12 种阶段攻击，采用 recover→telegraph→fire 状态循环；蓄力核心、旋转能量块、展开导轨、竞技场信标、目标危险光路、蓄力/释放 SFX 与阶段 8-bit 编曲共享同一状态。
- 军械超频、纳米花簇、神盾矩阵、磁通核心四类拾取 Buff 全自动运行，并有贴体模型、打击/拾取音效、HUD 和动态音乐信号；冰冻、干扰、破译分别影响移动、射速与能量。
- 第一章生态安全包络、前段标准构筑与侦察机保护，继续保留并发上限、慢弹和开局禁火。
- 玩法 RNG 与视觉/音色随机源隔离；同种子候选、敌人、弹幕与掉落不会被粒子表现扰动。
- 3D 与 HUD Canvas 均使用与显示尺寸匹配的高清缓冲；HUD 保留 480×270 逻辑布局并提供分辨率诊断属性。
