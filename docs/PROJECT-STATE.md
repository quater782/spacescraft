## 已建立能力

- Three.js 0.185.1 WebGL2 渲染；共享 `BoxGeometry` 通过按颜色缓存的 Toon 实体、全亮能量件和轻微 Glow 三类实例批次绘制，没有手写面片或光滑实体原语。
- 三种玩家机体使用现代航空战斗机比例：细长尖鼻、低矮机身、连续阶梯薄翼、贴体发动机与倾斜尾翼；普通/精英敌舰和 Boss 使用独立异形语言：弯月骨翼、分叉颚、甲壳、触须与非对称眼阵。双方使用高饱和多色积木，敌军反向 180° 朝向玩家，主体不存在近黑色结构块。
- 最近邻三阶 `MeshToonMaterial`、低强度同色自发光下限、ACES 色调映射、半球/方向/双机点光源、指数雾、双层星空和 3D 网格提供稳定科技光影；加法 Glow 外壳不与实体共面，已移除旧渲染器的闪面与 Toon 实例发黑路径。
- 九个星域拥有九套独立的积木微缩世界；近景航标、中景生态与远景地标组成三层纵深并持续向镜头推进。花簇、晶簇、彗流、极光、齿轮、云礁、嘉年华、棱柱墓园与虚空枝晶均有独立构造分支。
- 玩家四类弹体与敌军四类弹幕使用按速度方向排列的分段 Toon+Glow 拖尾；命中/爆炸粒子按速度拉伸为体积光屑，低画质自动压缩拖尾预算。
- 三章场景、九个编队事件、三场精英战和三阶段 Boss。
- 单人 AI 僚机与本地双人；玩家仅控制方向，射击、技能、共振与救援自动运行。
- 第一章难度保护、敌人并发上限、较慢敌弹、较长受击无敌与可读性选项。
- Web Audio 多轨 8-bit 配乐和分层音效；音乐/音效可独立调节。
- 三机体、四模组、三合约、星尘经济、八枚勋章与 v5 本地存档迁移。
- 完整中英双语目录与自动缺键检查。
- 15 项局内升级、章节间共享三选一、方向确认、三档稀有度、构筑摘要和可复现 run seed。
- 7 种两件套遗物协议；首次组件会让后续构筑确定性提供配套候选，并驱动高速齐射、屏障穿越、追踪蜂群、连锁电弧、护盾新星、拾取晶弹和共振强化。
- 9 种确定性星域生态；每章三选一，驱动 WebGL 光色、3D 地标、敌军节奏、敌型偏好和 8-bit 音乐 BPM/调式。
- 每章开场三座实体 3D 星门与 7 种确定性航线协议；方向汇合自动确认，风险/奖励驱动敌军构筑、战斗参数、得分和音乐，单人 AI 自动跟随 P1。
- 五类模块化动态遭遇；每章两个种子目标驱动信标同步、星骸回收、移动护航、陨星生存或裂隙攻坚，并拥有 3D 实体、共享奖励、失败回退和自适应音乐。
- 三分支九节点恒星天赋网格；星尘永久点亮机动、自动武装与双子共振效果，含前置依赖、v5 存档迁移和实际玩家参数接线。
- 全自动星链狂潮；双机编队与六类战斗事件充能，满槽后强化自动火力/光链/拾取/得分，光链消弹、击破延时、3D 轨道能量环、动态 8-bit 编曲与任务报告均已接线。
- 七个有机船体家族与推进、武器、核心、AI、载荷各四种模块形成 7,168 种完整敌军构筑；模块直接改变机头、翼根、核心舱、后翼与发动机轮廓，并驱动四类 3D 弹幕、目标/预判/侧袭/闪避、屏障/爆裂与三种 Debuff。
- 三章 Boss 分别使用花瓣魟翼、雷枪熔炉和双体虚空冠三套独立构造器；第二/三阶段会长出大型主体器官，三章弹体分别为花瓣、雷枪与旋转棱体。
- 三章 Boss 共 12 种阶段攻击，采用 recover→telegraph→fire 状态循环；蓄力核心、旋转能量块、展开导轨、竞技场信标、目标危险光路、蓄力/释放 SFX 与阶段 8-bit 编曲共享同一状态。
- 军械超频、纳米花簇、神盾矩阵、磁通核心四类拾取 Buff 全自动运行，并有贴体模型、打击/拾取音效、HUD 和动态音乐信号；冰冻、干扰、破译分别影响移动、射速与能量。
- 第一章生态安全包络、前段标准构筑与侦察机保护，继续保留并发上限、慢弹和开局禁火。
- 玩法 RNG 与视觉/音色随机源隔离；同种子候选、敌人、弹幕与掉落不会被粒子表现扰动。
- 3D 与 HUD Canvas 均使用与显示尺寸匹配的高清缓冲；HUD 保留 480×270 逻辑布局并提供分辨率诊断属性。
- Electron 桌面壳、可复现隐藏窗口冒烟、九生态矩阵、3+7 机体矩阵、三 Boss × 三阶段矩阵、Boss 状态动态实战、Windows CI、多分辨率图标与 0.21.0 Windows x64 归档。
