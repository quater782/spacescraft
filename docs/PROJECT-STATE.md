## 已建立能力

- 原生 WebGL 透视 3D、三章场景、九个编队事件、三场精英战和三阶段 Boss。
- 单人 AI 僚机与本地双人；玩家仅控制方向，射击、技能、共振与救援自动运行。
- 第一章难度保护、敌人并发上限、较慢敌弹、较长受击无敌与可读性选项。
- Web Audio 多轨 8-bit 配乐和分层音效；音乐/音效可独立调节。
- 三机体、四模组、三合约、星尘经济、八枚勋章与 v4 本地存档迁移。
- 完整中英双语目录与自动缺键检查。
- 15 项局内升级、章节间共享三选一、方向确认、三档稀有度、构筑摘要和可复现 run seed。
- 9 种确定性星域生态；每章三选一，驱动 WebGL 光色、3D 地标、敌军节奏、敌型偏好和 8-bit 音乐 BPM/调式。
- 移动、武器、核心各四种模块形成 64 种完整敌军构筑；拥有可辨认 3D 外挂、差异化弹幕/音色、屏障破碎与爆裂连锁。
- 第一章生态安全包络、前段标准构筑与侦察机保护，继续保留并发上限、慢弹和开局禁火。
- 玩法 RNG 与视觉/音色随机源隔离；同种子候选、敌人、弹幕与掉落不会被粒子表现扰动。
- 3D 与 HUD Canvas 均使用与显示尺寸匹配的高清缓冲；HUD 保留 480×270 逻辑布局并提供分辨率诊断属性。
- Electron 桌面壳、Windows CI、多分辨率应用图标与 0.9.0 Windows x64 免安装归档。

- 0.9.0：20 份 Markdown、291 个引用键 × 2 种语言、JavaScript 语法、15 项玩家升级、9 种生态、64 种敌军构筑、种子复现、第一章安全包络、后期多样性、3D 模块集成和正式依赖审计通过。
- 0.9.0 Windows ZIP/EXE 的 SHA-256、字节数、76 个归档条目、ASAR 版本和完整性见[打包指南](./PACKAGING.md)。
