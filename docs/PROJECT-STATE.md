## 已建立能力

- 原生 WebGL 透视 3D、三章场景、九个编队事件、三场精英战和三阶段 Boss。
- 单人 AI 僚机与本地双人；玩家仅控制方向，射击、技能、共振与救援自动运行。
- 第一章难度保护、敌人并发上限、较慢敌弹、较长受击无敌与可读性选项。
- Web Audio 多轨 8-bit 配乐和分层音效；音乐/音效可独立调节。
- 三机体、四模组、三合约、星尘经济、八枚勋章与 v4 本地存档迁移。
- 完整中英双语目录与自动缺键检查。
- 当前开发源码另含 15 项局内升级、章节间三选一、方向确认、构筑摘要和可复现 run seed。
- 3D 与 HUD Canvas 均使用与显示尺寸匹配的高清缓冲；HUD 保留 480×270 逻辑布局并提供分辨率诊断属性。
- Electron 桌面壳、Windows CI、多分辨率应用图标与 0.7.0 Windows x64 免安装归档。
