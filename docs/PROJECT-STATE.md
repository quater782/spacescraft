## 已建立能力

- Three.js 0.185.1 WebGL2 渲染；共享 `BoxGeometry` 通过按颜色缓存的 Toon 实体、HDR 能量件和轻辉光三类实例批次绘制，没有手写面片或光滑实体原语。体素边长至少 0.12 世界单位并按 0.04 量化，每块实体都有自发光下限和 3.8% 同色 Glow 壳。实战透视视场角为 55°，玩家模型使用 0.82 比例，普通/精英/Boss 敌机独立使用 1.18/1.40/1.32 比例。
- 三种玩家机体继续使用哑光陶瓷连续面、玩家识别色和深色座舱。敌军扩为 7 类通用机体 + 9 类生态原生种；蜜露蛾、棱晶魟、彗潮撞角兽、极光吸能体、雷轨甲虫、云礁水母、蚀影收割者、墓棱镜像与虚空孢巢各有独立 3D 剪影。激光器、追踪荚、爆破腺体、集群眼阵和伏击感官直接长在主体结构上。
- 三阶 `MeshToonMaterial`、ACES 色调映射、半球/方向/克制双机点光源、指数雾和三层星空提供稳定科技光影；EffectComposer 使用 Render → 五级 Unreal Bloom → SMAA → Output，1.03 阈值只让 HDR 能量器官发光，陶瓷和环境不泛白。像素感由粗颗粒几何承担，不用最近邻整屏拉伸制造锯齿。
- 九个星域改为开放深空构图：连续地板、导航网格、成对护栏和常驻门架全部移除；每区以一个巨型身份剪影、一组中景生态、两层 3D 加色星云尘带和稀疏航标形成不对称纵深，中央 55% 保持战斗负空间。背景生态限制在 -48 至 -18 世界深度带，不再周期性穿入玩家层。圆环、彗尾、极光、闪电、胞膜和枝条使用连续分段曲线，不再使用方点环。
- 九种活体星域异象按种子一局恰好遍历一次，接入战斗、资源、得分、HUD、结算与 Web Audio；渲染表现为偏轴局部天象，不形成左右对称跑道。
- 玩家普通弹使用低亮玩家色短矢，不再以白芯连成两条发光轨道；相位、追踪和重弹保留白芯。敌弹使用高饱和珊瑚红、紫色倒刺和少量载荷核；只有狙击/长枪职责保留长轴。
- 三章 570/600/630 秒基础航行合计 1,800 秒；每章三个递进战区、九个编队事件和一场三阶段 Boss，完整一局共九战区、27 次编队事件。
- 常规空战改为重复的“突入→交锋→杀伤区→释放”节拍；三章分别使用 24%/60%/82%、16%/43%/72%、12%/36%/84% 的节拍边界和独立压力/开火/弹速/航速/并发/编队向量，普通敌弹由 46–132 枚动态预算封顶。
- 七种敌军职责接入入场、占位、预警、攻击、脱离/重组六态循环；六种三机编队共享目标并错开齐射。普通敌机会持续跟随玩家当前站位，并按职责维持 112–176 逻辑单位的交战距离，不再依赖固定纵深或单一按船体直线脚本。
- 弹幕语法新增真实激光、恒速限角追踪和按目标距离引信的范围爆破；三类命中均能施加载荷，追踪窗口末端允许横切甩脱，非有限弹体会被丢弃并计入诊断。普通弹速度整体提高，狙击刺基础速度达到 108+。普通预警不再绘制敌机到玩家的通用牵引线：瞬发激光使用覆盖完整射线的细分段瞄准虚线，冲撞使用机鼻局部箭头和攻击尾迹，爆炸使用真实伤害半径环；实际激光由边缘导轨、灼热核心和定向能量包组成。

- 单人 AI 僚机与本地双人；玩家仅控制方向，射击、技能、共振与救援自动运行。
- 第一章前 6 秒禁火、前 8% 巡航封顶、开局标准侦察构筑、敌人并发上限、较慢敌弹与可读性选项继续保留；受击无敌缩短为 0.72 秒。移动模块从 8% 后教学，原生种、随机精英与随机高级武器对齐 25% 首次构筑，死亡机能在 42% 后开放。
