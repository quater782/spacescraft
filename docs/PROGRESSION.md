# 可恢复远征：收益、研究与压力节奏

2026-09-06 未发布实现；package 仍为 0.27.0，没有重建桌面发行包。本文件记录已接入源码的规则，不代表完整三章通关率已完成标定。

## 玩家路径

机库选择免费收益路线 → 出航完成战区/遭遇/首领 → 失败或胜利结算星尘与研究资料 → 自动解出随机永久蓝图 → 用星尘定向补强 → 下一局所有已解锁蓝图自动共存。

星尘仍是可支配的通用资源，不新增可购买的随机箱。研究资料仅是累计到四份自动结算的发现进度，不消耗星尘抽奖，也不会挤占已有天赋、机体和模组。

## 三条收益路线

| 路线 | 额外星尘 | 优先发现 |
| --- | --- | --- |
| 探索 | 每完成战区 +12；每成功遭遇 +6 | 导航信标、战地维修 |
| 回收 | 每件拾取 +3，每局最多 +72 | 回收编织器、通量拆解 |
| 攻坚 | 每个非 Boss 精英 +6，最多 +60；每 Boss +20 | 攻坚标记、脉冲护盾 |

路线只影响结算和蓝图发现方向，不关闭其他路线已有的效果。出航时快照路线与蓝图等级；新解锁下一局生效，不能中途切换获利。

## 星尘与发现规则

- 里程碑：每完整战区 32、每 Boss 80、每成功遭遇 22、全通额外 100 星尘。
- 普通击破奖励：每击破 2 星尘，全局最多 60；不再按无限连击得分追加局外收益。
- 上述收益加路线奖励，乘现有合约倍率 1/1.25/1.55；没有按待机时间发钱。
- 首次有效尝试（累计击破至少 12，或成功遭遇/Boss）保底 80 基础星尘，并额外赠送一份蓝图。`starterClaimed` 永久记录，不能反复早退领取。
- 每完整战区/成功遭遇提供 1 研究资料，每 Boss 提供 2。每 4 资料自动解出一份蓝图；不足四份的余量跨局保存，失败不清零。正常全通且十二遭遇全成功有 27 资料，即六份蓝图与三份余量，首次奖励另计。
- 每次结算的第一份优先当前收益路线；后续有可用路线蓝图时以 65% 选择该路线，否则从全部未满级蓝图中选择。所选池内先发现未拥有的蓝图，再随机提升等级。全满后每份转为 40 星尘。
- 随机流单独由 run seed、已完成出航次数和固定盐派生，先做整数混合；不消耗战斗、掉落、构筑或表现随机流。同输入可复现，相邻种子有实际分化。不存在付费重抽。

例如：首次仅完成 12 击破后失败，获得 80 星尘和一份蓝图；随后重复相同早退只获得 24 星尘、零蓝图。已经领取首奖后，两局各完成一个战区和一次遭遇，会跨局累积 2+2 资料，在第二次结算解出一份蓝图。该例验证规则，不声称所有玩家的每分钟收益相同。

## 六种永久蓝图

全部三阶；定向研究价格为 80/140/240 星尘，可从零级直接研究，不要求先随机抽到。六种同时生效，不占用单一核心模组槽；新蓝图不是局内卡池稀释项。

| 蓝图 | 一/二/三阶效果 | 行为变化 |
| --- | --- | --- |
| 导航信标 | 进入新的章内战区时，Nova +4/8/12，缺盾最多的存活队员 +1 盾 | 推进到新战区获得补给；相同战区不能重复刷 |
| 战地维修 | 遭遇成功后存活双机额外恢复 0.5/1/1.5 血 | 主动完成目标争取续航 |
| 回收编织器 | 每 8/6/4 件全队拾取给最缺盾的存活队员 +1 盾 | 走位接补给也能保护队友；满盾保留计数至下次拾取 |
| 通量拆解 | 任意拾取额外提供 2/3/4 基础 Nova 能量 | 补给路线可加快局部清弹，受已有充能倍率影响 |
| 攻坚标记 | 同一精英/Boss 每 8/7/6 次双机弹体命中，追加一次该弹伤害 | 集火大目标获得标记爆发；无敌阶段不积累，无额外弹体或连锁回能 |
| 脉冲护盾 | 每 3/2/1 次 Nova 给最缺盾的存活队员 +1 盾 | 清弹流获得有上限的护盾续航，不给自身充能 |

导航信标只在 `enterSector` 触发的真实战区切换中生效，不额外赠送开场护盾；每章两次章内换区都能触发。所有补盾尊重护盾上限、不复活倒地队员。已有主动效果仍自动运行，无新增战斗按键。护盾触发复用蓝色 3D 吸收反馈及分层吸收音效，攻坚标记使用局部金色命中碎屑；诊断可统计实际触发次数。

## 局内构筑与压力恢复

- 三章时长不变：570/600/630 秒。每章 10%/30%/52%/75% 四次章中构筑，加前两章 Boss 后的两次章间构筑，共 14 次。首抽约 57 秒。
- 22 张卡、四路径覆盖、稀有/传说保底、配套件和全部协议共存规则保留。没有统一提高所有卡的伤害倍率。
- 每次选卡后 12 秒暂缓普通随机增援，不删除敌人或弹幕，不关闭脚本编队/遭遇；高危普通敌方攻击槽从 2 降为 1，让新能力有短暂发挥窗口。
- 第一章节拍不变；第二章边界为 18%/50%/76%，第三章为 16%/48%/78%。第三章每个 70 秒节拍的高压为 21 秒，释放为 15.4 秒；此前高压 33.6 秒。
- 第三章压力基线 1.18、战区步进 7.5%；释放段的压力/开火向量分别 .84/.82。普通敌人仍会追猎，但释放段有至少五名存活敌人时暂缓普通随机增援，优先让玩家清理积压。
- Boss 前最后 10 秒停止普通随机增援，保留存活敌人，不用无提示清场代替走位。Boss 原有攻击和增援仍存在。
- 精英在普通增援并发预算中占 2.5 个名额；这不是对所有脚本生成的全局硬上限。
- 第二/三章普通增援和脚本编队分别以 12/14 为基础加权预算，杀伤区额外两名额；脚本成员会逐个检查余量，战术随机编队仍可能因队首精英权重产生小幅超额。Boss 自身招式的援军不由这一预算删除。
- 中后章普通敌人同时预警/攻击最多四名，释放/成长宽限/Boss 在场时最多两名；这个总队列先于下面的高危来源队列。第一章原有普通攻击节奏不改。
- 普通敌人的激光/冲撞/爆破高危攻击按来源预留槽位，已有伤害束和爆破弹也占位。一般上限 2；释放段、升级宽限和 Boss 在场时普通敌人上限 1。排队者返回恢复态后重新预警，不压缩或跳过预警。Boss 的招式不被此队列打断，此限制不等于全屏只有两种危险。
- 默认巡航合约不再因击破、连击、狂潮或共振额外提高动态难度。章节/战区自然进度仍抬升压力，残血/倒地仍减压；高难合约的成功动量最多 .25 分，且狂潮、共振不加压。
- 第一章前六秒禁火和前 8% 保护不变，随机高级武器、原生种和精英仍保留至 25% 后，意味着更早获得的卡有足够教学缓冲，而非同步提前危险。

## 存档与验证边界

profile 升级至 v6，同一 localStorage key；保留 v5 钱包、机体、模组、天赋、设置与统计。新增 `research: { focus, ranks, progress, starterClaimed }`，采用合法 ID、有限数值和 0–3 等级/余量清洗，损坏或缺失数据可回退。结算只执行一次，QA 快速模式不写生涯奖励。

规则验证：`npm run verify` 包含 `verify-research.mjs`，覆盖购买、坏数据、随机复现/分化、首奖一次性、资料跨局累计、满级转化、全部效果共存与击破收益上限。静态代理成长分不作为通关公平性证据。

实机入口为 `npm run smoke:progression`；`-- --fixtures-only --late-sample` 可跳过已检查的正常开局，并附带正常速度第三章十二选短场景。后者从受控中期状态开始，不是自然三章或真人通关测试；不据此报告通关率。具体结果见[项目状态](./PROJECT-STATE.md)。
