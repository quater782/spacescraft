# SPACECRAFT 0.25.0 — 高压空域

日期：2026-08-31

状态：源码开发快照。尚未生成或核验 0.25.0 Windows 发行归档；当前可追溯 Windows 产物仍为 0.23.0。

## Major 主题

把难度来源从平坦倍率和单机直线脚本，重构为有峰谷的 30 分钟压力曲线、会占位/预警/集火/脱离的敌军战术状态机、具有明确空间反制的弹幕语法，以及会在满级改变自动火力形态的成长系统。

## 本轮内容

- 每章九轮“突入→交锋→杀伤区→释放”压力节拍；章节、战区和动态威胁继续叠加，但普通敌弹由 46–132 枚预算约束。
- 七种船体职责接入入场、占位、预警、攻击、脱离/重组状态机；六种三机战术编队共享目标分配并错开齐射。
- 新编队会从五条战术航道中选择最空位置，成员分布到三层纵深并在预警前保留编队锚点，降低高压场景的中央团块。
- 新增 15 种弹幕语法，覆盖预判扇射、安全口弹墙、制动雷枪、曲线螺旋、延迟种雷、双侧夹击和指挥组合；WebGL 显示普通敌机锁定线、充能器官与警戒环。
- 第一章强制教学保护从前 40% 收紧到前 8%：前 6 秒继续禁火、20 秒开局仍可存活；8% 后开始开放移动/武器模块和更高动态威胁。
- 五级威胁矩阵的极限端提高到 1.38 增援/开火、1.20 弹速、1.18 耐久/航速与更紧预判；残血和倒地保护保留。
- 15 项局内升级改为非线性叠层；超频、棱镜、无人机和陀螺在满级产生新增弹型、出击节奏或碰撞体质变。
- 新增空构筑/四选中期/八选满级真实火力对照；满级追踪僚机改用低 Bloom 紫色短矢，保留弹量与伤害但不形成白色光墙。
- 单人 AI 改用弹道拦截时间、职责优先级和弹幕类型安全半径，继续承担目标、集火、共振、闪避和自动救援。
- 敌军模块扫描由中央横幅改为左侧 158×34 双行卡片，缩短显示并降低出现频率，避免遮挡主要火线。
- 新增耐久上限、位置、累计受击、倒地/救援次数等稳定诊断，以及同种子零输入/预警换位策略门禁；高压不再只以弹量和截图判断。
- 新增敌军重叠、近距挤压、最小净距和展开诊断，极限布局纳入自动上限。
- 新增只限本机的章节/进度高压采样参数、静态 `verify-combat` 和真实 Electron/WebGL `smoke:combat`、`smoke:strategy`。

完整规则见[空战高压设计基线](./COMBAT-DESIGN.md)。
