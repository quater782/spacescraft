# 0.7.0 发行说明：完整中英双语本地化

0.7.0 的 Major 主题是完整的简体中文/英文产品化，而不是只翻译标题菜单。本版本把展示文本与游戏数据彻底分离，让同一局战斗、同一份机库状态和同一张任务报告可以在运行中即时换语言。版本代号为 Localization Alpha，仍不是 Steam 发布候选版。

## 覆盖范围

- 主菜单、模式说明、键位提示、首次教学、暂停和设置。
- 三种机体、四枚模组、三种航线合约、解锁条件和八枚勋章。
- 三章名称与副标题、九种事件、三名 Boss、九个 Boss 阶段。
- 战斗 HUD、连击、共振、自动技能、救援、拾取、警告、章节净化与全部 Toast。
- 胜败标题、QA/正式任务说明、解锁勋章、四项结算统计与操作按钮。
- 页面标题、描述、HTML 语言标记、ARIA 名称和状态栏。

## 技术实现

`src/i18n.js` 是唯一的双语文案目录，提供键查找、变量插值、DOM `data-i18n` 更新与元数据同步。机体、模组、合约、勋章、章节、事件和 Boss 阶段只保存稳定键，不再把中文或英文写死在战斗数据里。

存档版本升级至 v4，在 `settings.language` 保存 `zh` 或 `en`。旧存档缺少该字段时会安全回落到简体中文；原有生涯、星尘、解锁、勋章和合约数据不会丢失。任务结算保存胜负和新纪录状态，切换语言后会按当前状态重新渲染，不会重复结算奖励。

`scripts/verify-localization.mjs` 会从 HTML 静态标记、游戏逻辑调用和数据键字段收集实际引用，再检查两种语言。当前验证范围为 212 个引用键 × 2 种语言，已接入 `npm run verify` 和 Windows CI。

- 从简体中文启动，在设置中切换英文：标题、ARIA、设置选项、菜单和状态栏即时更新。

- 装备脉冲 MK-III、共振透镜并签署过载合约；刷新后语言和三项选择全部保持。

- 英文结算显示 `QA CAMPAIGN CLEAR`、`THE STARS ARE OPEN` 和四项英文统计。
- 不离开结算页切回中文，任务标题、说明、四项统计、按钮与状态栏全部即时重绘。
- 浏览器错误/警告日志为空；JavaScript 语法、本地化覆盖和正式依赖审计全部通过。
