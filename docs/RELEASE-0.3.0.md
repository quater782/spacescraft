# 0.3.0 产品化迭代记录

## 本轮目标

让游戏在只有一名玩家时仍保留“双子协作”的核心体验，并补足桌面游戏必需的教学、暂停、设置与本地记录闭环。

## 单人 AI 设计

AI 僚机不是固定跟随点。每帧会综合以下目标生成移动向量：

1. 预估敌方弹体约 0.34 秒后的坐标，对 62 像素内威胁施加闪避权重。
2. 选择横向距离合适的存活敌机进行集火，同时把共振距离控制在约 88 像素内。
3. 低生命时更靠近 P1；P1 坠毁后立即把救援位置设为最高优先级。
4. 靠近场地边缘时加入回正力，避免 AI 被困在死角。

AI 仍遵守与真人相同的速度、碰撞、射击、技能和生命规则，不获得隐形伤害减免。

## 设置与存档

本地存档键为 `spacecraft-career-v1`，包含模式、教学状态、设置和生涯统计。存储不可用时游戏会保留当前会话并安全回退，不阻止开局。

画质档只改变 3D Canvas 内部分辨率，不改变固定时间步、碰撞或 HUD 清晰度：

- 性能：0.7 倍 CSS 分辨率。
- 平衡：1 倍 CSS 分辨率。
- 高清：跟随设备像素比，最高 2 倍。

## 当前发行边界

0.3.0 已形成可离线游玩的单人/双人桌面闭环，但仍属于 Product Alpha。Steam 商售前还需要完成完整三章压力测试、内容扩展、正式安装器签名、Steamworks、商店素材、多语言和 Windows 实机兼容性矩阵。

## 回归结果

- 标题页、单人/双人切换、首次教学和矢量设置界面显示正常。
- 音量与画质调整刷新后仍能从界面正确恢复；首次教学只出现一次。
- 飞行中打开设置会冻结世界，关闭设置回到暂停菜单，继续后恢复固定时间步。
- 单人无人操作 14 秒时 P1 与 AI 均为满生命；继续测试击破第一章 Boss，并正常载入云端铸造厂的 3D 地标与敌群。
- 浏览器控制台无日志、警告或错误。
- `node --check`、生产依赖审计、Windows x64 Forge 打包和 ZIP 完整性检查均通过。
