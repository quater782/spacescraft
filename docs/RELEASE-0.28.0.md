# SPACECRAFT 0.28.0 — 双子协同 / Twinship Synergy

发布日期：2026-09-18

0.28.0 是第一个同时面向 Windows 与 macOS 的稳定 GitHub Release。它汇总 0.27.0 快照之后的协作、敌军 AI 与反馈更新，并重建桌面发行链，解决旧 Windows 包资源缺失、测试停在航线选择以及只能获得单独 EXE 的问题。

## 玩家更新

- AI 僚机现在会评估追踪弹、曲线弹、激光、爆破、冲撞、陨石与敌机身体等真实威胁，在救援、集火和拾取前优先保持生存。
- 敌军机体移动与朝向解耦，可连续前后/横向平移；少量自适应芯片敌机拥有更好的预测、空位选择、同伴避让和躲弹能力，但不获得额外耐久、伤害或速度。
- 星链增加基础有限净空、断联充能保留与近身余效，并加入“折光护网”“Nova 回响”两张自动进阶任务卡；卡池现为 23 张。
- 护盾命中会读取真实入射方向与吸收伤害，破碎、重装和不同强度命中拥有可辨识的粒子与 8-bit 音色。
- 激光改为连续 3D 像素能量带，并按真实伤害、宽度、载荷与敌人级别改变亮芯、色带和火花。

## 正式桌面发行

- Windows 10/11 x64：当前用户安装器与完整免安装 ZIP。
- macOS：Apple Silicon arm64（M 系列芯片）的 DMG。
- 所有平台在发布前校验包内资源链；Windows x64 与 macOS arm64 还从包内 ASAR 打开菜单、机库、设置、语言切换和真实 WebGL 战斗。
- 包内冒烟先以正式 `file://` 检查菜单、设置、语言与 WebGL2，再只在测试进程的 localhost 映射同一 ASAR，以快速模式完成航线和战斗，确认双机存活与自动开火；不再依赖 CI 是否有活跃显示器。
- Squirrel 安装、更新和卸载事件在创建游戏窗口前处理；Windows 免安装包始终包含 EXE 所需的 DLL、`resources` 与 `locales`。
- 每个平台同时发布 SHA-256 清单。

## 首页与项目运营

- GitHub 首页改为中英双语首屏简介，并加入终阶军械齐射、星链狂潮、共享 Nova 三段 5 秒实机 GIF、静态截图、平台下载指引、操作表与当前版本摘要。
- GIF 与截图由当前 WebGL/Electron 实机生成；运行 `npm run capture:readme` 可重新生成素材。
- 仓库简介与 Topics 对齐“只需移动、自动战斗、本地合作、WebGL 3D”的核心定位。

## 验证边界

自动发行会在 GitHub 托管的 Windows x64 与 Apple Silicon macOS arm64 机器上完成构建和动态 WebGL 包内启动。项目不发布 Intel Mac 版本。当前产物尚未配置 Windows 代码签名与 Apple 公证；首次启动可能出现系统安全提示。完整 30 分钟双人真人通关、双手柄组合与多显卡覆盖仍是后续发行 QA 项目。
