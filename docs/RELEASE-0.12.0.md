# 0.12.0 发行说明：恒星天赋网格

0.12.0 的 Major 主题是把一次次航行连接成可持续的长期成长。机库现在拥有三分支、九节点的恒星天赋网格，玩家用星尘依次点亮矢量机动、自动武装和双子共振。每个节点都改变真实战斗参数，两架战机和单人 AI 使用同一效果；整个系统没有增加战斗按键。本版本代号为 Constellation Alpha，仍不是 Steam 发布候选版。

## 长期成长与玩法

- 矢量机动链依次提供移动速度、转向/拾取牵引、碰撞核心/受击无敌，强化只靠方向移动时的手感与容错。
- 自动武装链依次提供全武器伤害、射速/弹速、能量/超新星，使自动战斗拥有可规划的长期输出路线。
- 双子共振链依次提供光链距离、光链伤害/救援速度、护盾容量/出航护盾，强化单人 AI 与本地双人的合作回报。
- 每条分支按 80、140、240 星尘逐级点亮，总成本 460；完整九节点为 1,380 星尘。未满足前置或余额不足时不会扣款。
- 开场提示、任务报告、生涯摘要及 `data-talents`/`data-talent-count` 会显示当前长期构筑。

## 存档、安全与平衡

- profile 升级为 v5；v4 及更旧记录通过默认值合并补齐空天赋，既有生涯、星尘、机体、模组、合约、勋章、语言和设置继续保留。
- `sanitizeUnlocks()` 只接受九个稳定 ID，并按层级移除重复、未知及缺失前置的孤立节点，损坏数据不会绕过依赖。
- 天赋效果在创建玩家时统一应用，之后仍可与机体、模组、合约和局内升级叠加；没有消耗 run seed，也不会扰动敌军、掉落或表现随机序列。
- 本轮没有提高首章敌军数量、弹速或伤害，6 秒开局禁火、并发上限及第一章安全生态保持不变。

## 界面与音效

- 机库加入三列星链与层级连线，已点亮、可购买、余额不足和前置锁定拥有不同的边框、发光和文字状态。
- 功能图形全部使用内联 SVG、DOM 和 CSS；窄屏改为单列，未引入会因缩放模糊的位图图标。
- 九个名称、说明、分支、状态、提示与生涯文本完整支持简体中文和英文。
- 点亮天赋使用六音上行琶音、低频核心和高频噪声闪光组成的独立 8-bit 音效，与装备、拾取和局内升级反馈可辨。

## 工程与验证

- 新增 `src/constellation.js` 与 `scripts/verify-constellation.mjs`，覆盖九节点唯一性、三条完整前置链、购买门槛、存档清洗、全部数值效果及机库/运行时接线。
- `npm run verify` 通过：23 份 Markdown、387 个引用键 × 2 种语言、15 项局内升级、9 项长期天赋、9 种生态、7 种航线、5 类动态遭遇、64 种敌军构筑、JavaScript 语法与正式依赖审计均通过，0 个漏洞。
- `npm run smoke:electron` 在隔离 profile 中实际购买“矢量推进器”：余额 `3000 → 2920`、进度 `1/9`、双机速度 `91 → 96.46`；随后只用方向输入完成信标，得到 60 FPS、2142×1203 HUD、`relay:success`、`webgl: true` 与 `consoleErrors: 0`。
- 两张实际截图已检查：机库截图可见三分支、九节点、SVG 图标和依赖状态；战斗截图可见透视网格、3D 战机、共振光链、清晰 HUD 和 0.12.0 页脚。
