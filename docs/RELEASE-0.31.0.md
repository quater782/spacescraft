# SPACECRAFT 0.31.0 — 场景星图 / Scene Constellation

发布日期：2026-09-25

0.31.0 让九个星域从同一套堆叠背景中分离出来：每个战区现在以一个清晰的 WebGL 3D 主景、独立色调和战斗留白组织。方舟、晶冠、行星、轨道站、感应环、断碑与裂环各自只在对应星域出现，并以真实几何、透视、灯光和雾保持深度。玩家仍只需移动；射击、能量技能、共振和近距离救援继续自动触发。

## 玩家更新

- 九个星域拥有明确的主景构图，移除会遮挡战斗阅读的通用行星、零散装饰、中央白色过渡块、异象装饰实体和威胁悬浮信标。
- 远景动画改为可见的结构运动：行星地表与分层云带以不同角速度移动，轨道站、方舟、晶冠与断碑缓慢偏航，感应环和裂环的内外圈错向旋转。暂停时所有场景动画冻结。
- 三档画质保持相同主景比例，低档只减少背景密度。场景色调、相机、灯光、雾和 Bloom 由统一配置管理。
- 护盾外缘保留已存在的多点传导效果；低容量场景下的轻重受击、吸收与溢出在三档画质均通过真实碰撞和 GPU 外缘位移检查。

## 技术与兼容

`src/scene/` 负责场景配置、环境资源、地标和事件可视层；`renderer3d.js` 只消费该统一入口。移除了旧 2D 背景、重复生态生成器和无效星空更新，且视口尺寸只在变化时更新。没有新增运行时依赖、存档字段或手动战斗操作；现有存档保持兼容。

## 验证边界

完整 `npm run verify` 通过。九生态低/均衡/高画质矩阵均达到 60 FPS，零表面/粒子丢弃和页面错误；场景动态审查确认暂停冻结，并已查看九宫格连续帧及行星、轨道站、裂环的三段正常速度 WebGL 录像。异象、机体/模块和正常首章专项继续通过。
