# 0.14.0 发行说明：双子遗物协议

0.14.0 的 Major 主题是把局内升级从独立数值堆叠提升为可规划、可发现且会改变自动战斗形态的两件套协议。15 项既有武器、机动和系统升级现在能组成 7 种遗物协议；第一次选择会影响下一次候选，但确认和战斗仍然只需要方向输入。本版本代号为 Relic Protocol Alpha，仍不是 Steam 发布候选版。

## 七种协议

- **彗星驱动**（超频扳机 + 糖星涡轮）：移动达到机体速度 42% 后自动射速 +18%，每第四轮齐射追加两枚侧翼彗弹。
- **相位长枪**（方块磁轨 + 相位机壳）：全部弹体伤害 +12%、半径扩大、穿透 +1；命中模块屏障后继续飞行。
- **棱镜蜂群**（棱镜阵列 + 双子僚机群）：每次自动僚炮齐射追加两枚彩色追踪碎片，以固定步持续修正速度方向。
- **风暴回路**（穿透像素 + 连锁反应堆）：击破后的连锁伤害 +45%、搜索半径 +14，并额外连接一个目标。
- **神盾新星**（循环泡泡盾 + 紫晶爆芯）：护盾吸收攻击或自动恢复时触发微型新星，清理 64 范围敌弹并伤害 72 范围敌人；内部冷却 2.2 秒。
- **打捞反应堆**（星屑牵引束 + 超新星电容）：每次拾取额外获得 18 能量、8 狂潮充能并向八方向自动发射绿晶弹。
- **共振陀螺**（双子共振阵 + 零重力陀螺）：共振编队充能速度 +80%，光链伤害 +25%、命中宽度 +5。

## 构筑导演与确定性

- `SpaceRelics.injectProtocolChoice()` 在基础三选一生成后检查当前升级；若恰好拥有某协议的一半，则使用玩法 RNG 选择一件仍可升级的配套组件，替换同类别候选。
- 正常构筑仍保持武器、机动、系统各一项；玩家可以选择协议候选，也可以主动放弃并走其他路线。
- 同一 run seed、相同选择历史会得到相同配套候选；协议规则不读取表现随机源，3D 动画也不会改变后续敌军、掉落、路线或遭遇序列。
- 任务报告记录最终协议；`data-protocols`、`data-protocol-count` 和 `data-protocol-procs` 分别公开稳定 ID、数量与自动触发次数。

## 3D、矢量界面与音频

- 构筑候选使用协议色边框、“将激活”徽记及代码生成 SVG 图标；战斗构筑托盘追加协议芯片，HUD 显示首个协议和触发计数。
- WebGL 根据协议数量在双机中心生成多层彩色轨道环，并使用体素方块、八面体和楔形网格组成旋转遗物；双机上方各有协议核心，触发时扩大/发光。
- 协议上线音效由七音上行、长低频核心和噪声展开组成；自动触发使用短促三音与高通噪点，不与射击、拾取、狂潮和遭遇反馈混淆。
- 音序器在第 5/13 个十六分音符注入由协议 ID 派生的双音信号，与生态、星门、遭遇、Boss 和狂潮层继续叠加。
- 初版动态颜色曾使用内联 style，被 Electron 的 `style-src 'self'` 正确拒绝；最终实现使用七个固定 CSS 类，没有放宽 CSP 或引入 `unsafe-inline`。

## 平衡与性能

- 本轮没有修改敌军耐久、伤害、弹速、刷怪倍率、第一章敌军池或并发上限，协议全部是玩家侧自动协同。
- 追踪弹只搜索未命中过的存活敌人并保持原速度；友方径向弹增加上下左右完整边界回收，避免离屏对象长期堆积。
- 神盾新星只有在真实护盾吸收/恢复时触发，且由每机冷却限制；任意协议都不提供 AI 专属规则。
- 轨道遗物复用初始化时创建的 WebGL 网格与缓冲，每帧只提交矩阵和材质，不动态创建 GPU 资源。
