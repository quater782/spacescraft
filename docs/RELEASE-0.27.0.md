## Major 主题

把“开局自带的持续清场”拆回有代价、有方向选择的四条构筑路径。双机只共享一次 Nova，星链狂潮首先服务于换位，随机选牌、临时 Buff、掉落、视野和碰撞同时重标定；玩家仍然只控制方向，射击、Nova、狂潮、共振和救援全部自动触发。

## 共享 Nova

- 两架战机镜像同一个 120 点 `world.novaCharge`，不再各自拥有一次大招。未构筑被动充能为 1.2/秒，仅靠时间需要约 100 秒；命中基础充能为 0.06，且全队每秒原始命中充能最多 0.35。
- 每次触发把共享槽归零并进入 28 秒硬冷却。Nova 自身击破不会回充；同一帧已被净空的地雷或爆破种会立即短路，Nova 击破也不会在安全区触发死亡机能反扑。
- 基线只清除任一存活战机 76 半径内的普通敌弹，对 96 半径内普通敌人造成 30 伤害、Boss 造成 18 伤害；远处弹体和激光束保留。
- `capacitor`、`novaCore`、`novaHarvester`、`novaAegis` 与 `novaPurifier` 分别扩展充能效率、伤害/半径、击破充能、护盾/救援充能和全屏普通弹净化。全屏净化是传说卡，并以 Nova 伤害降低 15% 为代价；激光始终不被清除。

## 星链狂潮

- 基线狂潮持续 6 秒，结束后冷却 9 秒；只提供移速 ×1.12 与操控 ×1.18，射速、伤害、光链伤害、牵引和得分保持 ×1。
- 启动不清弹、不清激光、不补 Nova，也不自带光链偏转；普通/精英击破和拾取默认不提供事件充能。连线仍以 0.55/秒缓慢积蓄，失联以 0.22/秒衰减。
- `resonanceArray`、`rushRelay`、`rushSalvage`、`rushOverdrive` 与 `rushGuard` 分别扩展连线充能、击破充能、拾取/遭遇充能、爆发输出和有限偏转。偏转每 0.28 秒最多一弹，每次狂潮最多 20 弹。

## 抗欧非成长

- 局内卡池由 15 张扩为 22 张，组成武装、机动/生存、Nova 和狂潮四条稳定路径；15 个既有 ID 保留。
- 首两次三选一合计覆盖四路径；之后每次保留当前主路径并补最弱路径。每两次候选至少出现一张稀有或传说，第 5–7 次选择窗口必有传说，发现位不会连续重复同一张卡，也不会提供已满级卡。
- 拿到遗物协议首组件后，配套件只在随后两次构筑内保证出现一次；同时只保留最近完成的一个主协议，避免多协议乘算滚雪球。
- 20,000 个种子的八选离线对照中，随机选择、单路径专精和稀有优先的成长分 P90/P10 分别为 1.0321、1.0169、1.0276。
- 军械 Buff 收束为伤害 ×1.06、射速 ×1.12；通量 Buff 的共享充能为 ×1.15。重复拾取只刷新并最多额外延长 1 秒，不再无限叠时长。

## 掉落与随机流

- 战斗、构筑、掉落、航线和表现使用五条由 run seed 派生的独立 RNG 流；粒子或音色消耗不会改写敌人、候选或掉落。
- 普通击破累积 0.08–0.105 掉落预算，重型敌人额外 +0.1；因此普通击破最长掉落旱期不超过 13 次。
- 武器、维修、护盾和能量使用四类洗牌袋。武器拾取同时升级双机；单人模式的维修/护盾会给僚机一半效果；能量直接进入共享 Nova。

## 视野、比例和判定

- 相机由 52° 扩为 55°；实战玩家模型缩至 0.82，普通/精英/Boss 敌机使用独立 1.18/1.40/1.32 比例并移除旧远景放大，敌机逻辑半径同步缩小约 7%–9%。
- 玩家判定拆为受弹核心、机体接触和拾取感应三圈。彗星为 3.2/3.6/5.5，壁垒为 3.6/4.1/6.2，脉冲为 2.8/3.3/5.0；敌弹/爆破、撞击和拾取不再借用同一个半径。
- 基础受击无敌由旧 1.8 秒缩到 0.72 秒；相位外壳每级只增加 0.07 秒，结合长期天赋后的总上限为 0.94 秒。纯护盾吸收只给 0.22 秒接触去抖，救援保护为 1.2 秒。

## 敌方意图与激光表现

- 普通敌机不再向玩家绘制没有玩法效果的通用牵引线。七种职责会追踪玩家当前站位，并在各自 112–176 逻辑单位的安全交战距离附近接近、后撤和重新占位。
- 只有瞬发激光保留跨屏方向预警；长枪和扫掠至少预警 1.12/1.28 秒，使用覆盖完整射线的细分段虚线。预警线本身不造成伤害，因此保持克制、清晰且不与玩家形成视觉绳索。
- 实际激光由双侧边缘导轨、彩色束身、灼热白芯、定向能量包和发射口光晕构成。冲撞改用机鼻局部箭头与穿点攻击尾迹；死亡爆炸和爆裂核心在残骸处延迟 0.68/0.72 秒，以真实伤害半径环预警。

## 实机证据

- `npm run smoke:reactor`：两个真实 Electron/WebGL 会话中，Nova 连续触发两次且最短间隔 28.02 秒；累计局部清弹 28、全屏清弹 0，触发后保留 64 枚远弹和 2 条激光。净空的地雷/爆破种生成 0 残片，Nova 击破的 1 次死亡机能被压制。基线狂潮完整通过 6 秒激活和 9 秒冷却，启动/偏转清弹均为 0。两场均 60 FPS、0 应用控制台错误。
- `npm run smoke:growth`：基础/四选/八选射速为 1.00/1.12/1.19，六秒齐射 33/41/48，玩家弹峰值 16/55/98；三种武装终阶在双机上全部触发，三档均存活并保持 60 FPS。
- `npm run smoke:strategy`：同种子第三章极限场的 12 秒对照中，零输入双机承受 14 点伤害并双双倒地；预警横移样本承受 13 点伤害，仅 AI 僚机倒地，P1 以 1 点耐久存活。两场均达到 129 枚以上敌弹、60 FPS，并捕获 AI 集火/闪避。
- `npm run smoke:combat`：正常速度首章前 20 秒峰值 4 敌/4 弹、双机满耐久；第三章极限杀伤区六秒峰值 21 敌、112 弹、8 编队和 6 类弹幕，普通 132/死亡机能 144 硬预算零越界。三章 × 四节拍 12 格矩阵全部保持 60 FPS。
- `npm run smoke:boss-state`：三章 phase 3 分别达到 75/101/128 枚敌弹和 12/2/4 条伤害束，所有弹体有限、预算零越界、60 FPS、0 应用控制台错误。
- `npm run smoke:models`：3 架玩家战机与 16 类敌机同屏画廊为 55 FPS、WebGL true、0 应用控制台错误；缩放后的实战、狂潮、满构筑和第三章极限截图已人工检查。
