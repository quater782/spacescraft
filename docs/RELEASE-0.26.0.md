# SPACECRAFT 0.26.0 — 掠食生态

日期：2026-09-01

状态：源码开发快照。尚未生成或核验 0.26.0 桌面发行包；当前可追溯 Windows 产物仍为 0.23.0。

## Major 主题

让敌军从“飞过屏幕的低耐久靶子”变成会留在战区、能以武器和智能器官协作捕猎、碰撞与死亡都会改变空间局势的九生态掠食群。玩家仍然只控制方向，所有武器、技能、共振和救援继续自动触发。

## 设计闭环

- 成长速度降低：普通掉落减少，齐射封顶收束，15 项升级的倍率、终阶节奏、维修和能量循环整体下调；八选满构筑实机击破只比基线约高 2.25 倍，不再在同一窗口高出五倍以上。
- 难度不是一根上升直线：三章分别使用 24%/60%/82%、16%/43%/72%、12%/36%/84% 的四段边界和非比例压力/开火/弹速/航速/编队向量；首章提供更宽学习段，中章强调交叉火力，终章把杀伤区延长到 48%。首章前六秒与前 8% 安全包络不变。
- 九生态都有原生种：每区一套独立轮廓、招牌攻击、死亡机能、碰撞伤害、偏好武器和偏好 AI；战术小队领机保证展示当前生态身份。
- 三类新武器都产生后果：激光预警后形成真实伤害束，追踪弹保留目标身份、恒速限角转向并允许玩家在末端横切甩脱，爆破种按目标距离设定引信并生成范围伤害和碎弹环；光束、追踪与爆破命中均可施加载荷。
- 六类智能器官改变作战行为：哨戒、猎杀、侧袭、预知之外，集群机同步蓄力与包夹，伏击机贴边占位后高速切入。七职责六态状态机继续提供站位和节奏骨架。
- 存活敌军不再自动退场：它们在占位、预警、攻击、脱离/恢复之间循环，直到被击破；Boss 出场不会清空幸存者，未解决的敌军会进入 Boss 战继续追猎。
- 机体是武器：玩家撞敌至少承受 3 点伤害，敌军按最大耐久受到重创；敌军高速相撞同样双方受伤、强制分离并允许触发死亡连锁。
- Boss 光路不再是装饰：三章基础耐久为 420/640/920；日耀枪、雷墙和双轨炮会生成真实光束，后期技能加入追踪与范围爆破。
- 常规精英不再只靠固定事件出现：首章前 12% 保护段后，自然生成概率会随章节、航程、威胁和杀伤区从约 6% 提升到 24%，耐久为同构筑普通敌机的 4.8 倍。

## 内容规模

- 16 类敌军船体：7 类通用机体 + 9 类生态原生种。
- 4 航行模块 × 7 武器模块 × 4 核心模块 × 6 AI 模块 × 4 载荷模块。
- 43,008 个稳定六维构筑签名。
- 21 种静态门禁可枚举攻击语法，另有 12 种 Boss 阶段技能序列。
- 模型矩阵为 3 架玩家战机 + 16 类敌机，实测 54 FPS、WebGL true、0 应用控制台错误。

## 实机证据

- `npm run smoke:arsenal`：五场真实 Electron/WebGL 会话分别验证带载荷激光、带载荷范围爆破、恒速限角追踪、机体碰撞和持续追猎；追猎样本存活 19.85 秒并完成 7 轮攻击。五场均 60 FPS、非法敌弹 0、0 控制台错误。
- `npm run smoke:combat`：首章正常速度开场峰值 3 敌/1 弹且双机满耐久；第三章极限场 9 秒内达到 21 敌、111 敌弹、10 编队与 9 类实发弹幕，60 FPS、弹量零越界。三章 × 四节拍 12 格矩阵全部为 60 FPS，并验证三套非比例曲线和杀伤区→释放回落。
- `npm run smoke:threat`：独立首章开场峰值 4 敌/6 弹、双机最低耐久 6、无倒地。
- `npm run smoke:strategy`：相同第三章极限场中，预警换位将小队累计伤害从 18 降为 13、倒地从 1 次降为 0 次；AI 继续表现集火与闪避。
- `npm run smoke:growth`：基线/四选/八选击破 4/8/9，射速 1.000/1.188/1.354，八秒齐射 44/54/71，玩家弹峰值 14/60/116，三种终阶全部触发。
- `npm run smoke:boss-state`：三章 phase 3 矩阵分别达到 75 弹/12 束、89 弹/2 束、122 弹/2 束，捕获激光、爆破与追踪招式并造成实际伤害；三场均 60 FPS、伤害束坐标有限、非法敌弹 0。
- `npm run verify`：文档、双语、语法、成长、战斗、远征、威胁、异象、Boss、渲染与依赖审计通过。
