# 0.16.0 发行说明：航空战机与异形舰锻造

0.16.0 的 Major 主题是建立清晰对立的两套 3D 美术语言，并把“模块化”从表面贴件升级为真正的机体架构。玩家是可辨识的现代航空战斗机；敌军是弯月骨翼、分叉颚、甲壳、眼阵与触须组成的异形生物舰。功能模块改写主体器官与发光脉络，不再把微型方块贴在同一套粗机身上。本版本代号为 Integrated Airframe Foundry，仍不是 Steam 发布候选版。

## 玩家机体

- 彗星 MK-I：细长尖鼻、翼身融合后掠翼、贴体双发、长轴座舱和双垂尾组成均衡制空战机轮廓。
- 壁垒 MK-II：保持低矮截面的宽幅薄翼、双侧装甲发动机舱和双垂尾组成重型攻击机轮廓，不再用四列粗机身表达重量。
- 脉冲 MK-III：针形机鼻、最窄中央机身、短翼高速布局和单发主引擎组成截击机轮廓。
- 军械、维修、护盾和通量 Buff 分别成为翼根炮轨、后机身维修脊、翼缘导轨和中央能量脊；异常状态成为贴合机身截面的发光带。

## 七个敌军船体家族

| 船体 | 战斗角色 | 主要轮廓 |
| --- | --- | --- |
| 月牙侦猎体 | interceptor | 低矮核心与向后弯曲的月牙骨翼 |
| 刺矛突袭体 | striker | 极细脊柱、双刺颚与非对称侧鳍 |
| 甲壳壁垒体 | bulwark | 低截面分节甲壳与外展护甲肢 |
| 星镰炮击体 | artillery | 四向镰臂与中央单眼火控核心 |
| 魟翼播种体 | denial | 魟形弯月翼、偏置眼核与多节触须尾 |
| 双颚枪骑体 | flanker | 不等长双颚长刺、负空间中心与侧袭骨翼 |
| 深渊母巢舰 | command | 双叶母巢、空心中轴、长触须与发光孢脉 |

枪骑体在第二章后以高速弧线侧袭并双发预判射击；母巢舰在终章停驻航道上部，同时释放环形压制与单发瞄准火力。第一章前段继续只出现安全月牙侦猎体标准构筑。

## 有机六维构筑

船体与五类功能模块形成 7 × 4 × 4 × 4 × 4 × 4 = 7,168 个唯一构筑：

- 航行模块重塑尾部触须、推进器官数量和左右不对称弯曲。
- 武器模块重塑单刺、双颚、狙击长脊或横向镰臂。
- 核心模块重塑甲壳骨板、屏障能量膜或中央爆裂囊。
- AI 模块重塑单眼、双目猎手阵、偏置侧眼或先知感知冠。
- 载荷模块重塑表面霜脉、扰频色带或裂解孢囊导流线。

所有结构仍由 Three.js `BoxGeometry` 实例体积组成。模型不包含手写面片、光滑球体或圆环，也不依赖贴图分辨率；平面法线 PBR、自发光实例与放大辉光外壳继续分层绘制，避免共面闪烁。

玩家弹幕也拆分为标准轨道弹、重型核心弹、追踪箭弹和相位长枪四种立体轮廓；敌军脉冲、双联、狙击与环轨弹继续由武器模块决定长度、宽度、旋转方式和载荷发光节点。

## 验证证据

- `npm run verify`：27 份 Markdown、本地链接、415 个引用键 × 2 种语言、7 个船体、7,168 个唯一构筑及既有玩法系统通过。
- `npm run smoke:electron`：Three.js WebGL2、60 FPS、2142×1203 HUD、0 应用控制台/CSP 错误。
- 完整状态面强制 `carrier.drift.orbit.barrier.oracle.cryo`，确认六维诊断、四 Buff 与 P1 冰冻。
- 干净机体面强制 `lancer.rush.sniper.volatile.hunter.fracture`，确认双颚枪骑体、三发推进器官、狙击长刺、爆裂核心、猎手眼阵和裂解脉络同时成为主体结构。
- 方向输入完成信标、协议自动触发和星链狂潮 +540 结算继续通过，没有增加战斗按键。

内置浏览器控制层在当前宿主初始化时冲突，因此没有把该路径列为通过；真实 Electron 窗口截图和 WebGL2 诊断已完成。
