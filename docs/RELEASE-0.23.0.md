# 0.23.0 发行说明：自适应威胁矩阵

0.23.0 的 Major 主题是让 30 分钟远征从固定难度曲线升级为会读懂队伍状态的动态压力系统。本版本代号为 Adaptive Threat Matrix：熟练队伍能把后期推向更快、更密、更高收益的极限节奏；受伤或倒地的队伍会得到明确且可逆的减压窗口。系统不增加战斗按键，仍然只需控制方向。本版本仍不是 Steam 发布候选版。

## 五级规则

`src/threat.js` 定义缓冲、巡航、交锋、激涌与极限五个稳定等级。评分读取章节、战区、章节进度、航线合约、连击、近期击破动量、星链狂潮、双机共振、平均耐久、倒地人数和六秒近期受击；候选等级需稳定 1.25 秒，实际档位每次只移动一级。

| 等级 | 增援 | 弹速 | 开火 | 耐久 | 移动 | 瞄准误差 | 击破收益 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 缓冲 | 0.82 | 0.84 | 0.84 | 0.92 | 0.94 | 1.16 | 1.00 |
| 巡航 | 0.94 | 0.92 | 0.94 | 0.97 | 0.98 | 1.08 | 1.00 |
| 交锋 | 1.00 | 1.00 | 1.00 | 1.00 | 1.00 | 1.00 | 1.05 |
| 激涌 | 1.08 | 1.05 | 1.08 | 1.05 | 1.04 | 0.91 | 1.12 |
| 极限 | 1.16 | 1.09 | 1.14 | 1.10 | 1.07 | 0.84 | 1.22 |

首章前 40% 最高只能到巡航；双机平均耐久低于 52% 时同样封顶巡航，低于 34% 或任一队员倒地时直接进入缓冲。Boss 自己的 recover→telegraph→fire 状态机不被倍率加速，避免破坏已有招式预告窗口；敌弹的档位倍率只在生成时写入，不会让屏幕中已有弹体突然变速。

## 战斗与表现闭环

- 普通敌机的生成节拍、并发预算、耐久、航速、开火、弹速和精度读取同一档位；击破收益随压力提高，避免高难只增加拖沓。
- HUD 右侧常驻 1/5–5/5 彩色等级、名称和刻度；等级变化有脉冲、升压/减压双语提示和不同方向的 8-bit 音效。
- 3D 航道以同色 Toon+Glow 体素信标显示五段压力，激涌与极限展开顶部警戒桥；只使用共享 `BoxGeometry` 实例，不引入面片或新运行时依赖。
- 动态配乐按档位获得 -3 至 +8 BPM 偏移和 0.90–1.24 强度倍率；高压增加高音琶音、噪声打击与额外底鼓，Boss 与狂潮现有层仍继续叠加。
- 任务报告记录峰值、调整次数、缓冲累计秒数和极限累计秒数；Canvas 同时公开当前/目标/峰值、连续分数和五项战斗倍率，供后续长局平衡采样。

## 验证证据

- `npm run verify`：文档、语法、419 个引用本地化键 × 2、15 项升级、九天赋、七协议、四 Buff/三 Debuff、30 分钟导演、五级威胁、九生态、7,168 敌型、Boss 状态和 Three.js 渲染门禁通过；正式依赖审计为 0 漏洞。
- `npm run smoke:threat`：真实 Electron/WebGL 缓冲与极限两端均为 60 FPS、WebGL true、0 应用控制台错误；实测倍率与上表一致。脚本另以 1× 时间运行首章前 20.07 秒，记录最高巡航、前六秒零敌弹、最多五架敌机/七枚敌弹、双机均保持 7 耐久与 60 FPS；`relief.png`/`apex.png` 已人工复核，HUD、五段航道信标、饱和 Toon 色块和克制 Glow 可读。
- `npm run smoke:director`：第一章压缩运行依次捕获战区 1/2/3、事件 9/9、遭遇 4/4、两次章中构筑与 Boss，60 FPS，0 应用控制台错误。
- `npm run smoke:electron`：真实桌面会话继续通过天赋购买、方向输入、自动信标、协议、四 Buff、狂潮结算和两组六维敌军路径；战斗/建模均为 60 FPS、WebGL true、0 应用控制台错误。

强制双端矩阵证明倍率和表现接线成立，但不替代正常 1× 30 分钟长局对自然档位分布、倒地减压和恢复升档的体验验证。
