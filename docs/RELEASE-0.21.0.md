# 0.21.0 发行说明：Boss 战斗编舞协议

0.21.0 的 Major 主题是把三章 Boss 从“按固定计时器持续发弹”升级为可读、可扩展的战斗状态机，并让蓄力、弹幕、竞技场灯光、音效与 8-bit 配乐响应同一个攻击状态。本版本代号为 Boss Choreography Protocol，继承 0.20.0 的三套阶段生长有机体，仍不是 Steam 发布候选版。

## 十二种阶段攻击状态

- 第一章拥有花瓣爆发、日光长枪、种子螺旋与双重花冠；第二章拥有雷轨墙、雷鸣扇射、熔炉十字与双轨压制；第三章拥有螺旋冠、虚空钳击、双蚀环和三重蚀环。
- 每章三个阶段使用不同的确定性攻击序列：阶段越高，可用攻击越多，恢复时间逐步缩短；同一 seed 和阶段可复现相同编舞。
- Boss 循环正式拆成 `recover → telegraph → fire`；预告开始时锁定目标位置，预告完成才产生弹幕。阶段切换会清除旧攻击、重置恢复时间并保持原有无敌换相窗口。
- 召唤副舰仍使用独立计时器，因此不会阻塞主攻击状态，也不会把召唤逻辑伪装成第四个按键。

## 体素预告与竞技场光路

- 三套 Boss 在预告阶段会激活搏动核心、6–12 枚旋转能量块以及章别色大型器官；瞄准类攻击长出三叉能量导轨，环射类攻击展开双侧蓄力翼。
- Boss 战新增两侧流动竞技场信标；瞄准时会在玩家侧生成五段地面危险光路，提示被锁定的横向位置。全部仍由实例化 `BoxGeometry` 构成，无 Plane、手写面片或光滑原语。
- 3D Canvas 新增 `data-boss-choreography="telegraph-state-arena"`；HUD Canvas 公开当前 `bossAttackState`、`bossAttack`、`bossAttackCharge` 与敌弹数量，便于动态验证。

## 史诗 8-bit Boss 编曲与音效

- 第二阶段加入与章别琶音交错的高八度节奏层，第三阶段加入低八度锯齿持续音和三音和弦重击；Boss 仍保持各生态 BPM、调式和航线偏移。
- 蓄力期间根据实际 charge 连续抬升音高和噪声截止频率；攻击释放使用独立低频冲击、下降音簇和爆破噪声，不再复用普通敌方开火音。
- 新增 `bossCharge` 与 `bossAttack` 分层 SFX，音乐/音效总线和用户音量设置继续生效。

## 动态实战回归

- 新增仅 localhost 生效的 `qa-boss-state`，快速进入高耐久第一章 Boss 且在专用会话中免除玩家伤害，用于观察完整状态循环，不影响正式游戏。
- 新增 `npm run smoke:boss-state`：真实 Electron/WebGL 中动态采样 Boss 数据，必须看到 recover 与 telegraph、至少两种攻击、charge ≥ 0.6、实际敌弹生成、50 FPS 下限和零应用控制台错误。
- 本轮实测捕获 `petalBurst` 与 `sunLance`，最大蓄力 0.82、同屏敌弹 12、60 FPS、WebGL true、零应用控制台错误；专用截图已人工复核。
- `npm run smoke:bosses` 的三阶段画廊继续通过 53/60/60 FPS，并显示新增蓄力能量器官。

## 尚未解除的发行阻断

- 当前普通三章基础航行仍为 126 秒，尚未达到策划要求的 30 分钟；下一 Major 必须增加阶段时长、事件密度、中段构筑和正常时长自动回归，不能只拉长空白计时器。
- 三场 Boss 正常速度全阶段、高密度弹幕与 7,168 敌型代表矩阵的长时间性能/内存回归。
- Windows 10/11 多 GPU/双手柄、代码签名、安装器、Steamworks、商店 Capsule、预告片和正式支持资料。
