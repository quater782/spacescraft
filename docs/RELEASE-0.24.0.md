# SPACECRAFT 0.24.0 — 活体星域异象

日期：2026-08-30

状态：源码开发快照。尚未生成或核验 0.24.0 Windows 发行归档；当前可追溯 Windows 产物仍为 0.23.0。

## 本轮内容

- 九个战区按航行种子各生成一种不重复的活体异象；晶寂、离子花潮与彗星顺流组成首章安全池，后续六种逐章开放。
- 异象同时进入敌军节奏、玩家机动、敌我弹道、资源、得分、HUD、结算和 Web Audio 动机；不增加任何战斗按键。
- 视觉基线重铸为开放深空：移除连续地板、导航网格、成对航道护栏和横贯画面的门架，采用三层星空、偏轴天体、限制在 -48 至 -18 世界深度带的背景生态和低饱和遗迹。
- 九生态重做为种荚母巢、水晶冠、三带彗星、极光环锻炉、电磁线圈、胞膜云礁、双日冕蚀月、三碑断拱墓园与双环奇点花园；圆环、彗尾、极光、闪电、胞膜和枝条使用连续分段曲线，不再排列成点阵门。
- 玩家统一为灰蓝/暖灰哑光陶瓷风筝形战机，P1/P2 分别使用青蓝和珊瑚识别色；分段锥形机鼻、四段薄翼、贴翼四片护盾与压入轮廓的四类模组共同保持简洁，装甲、座舱和引擎在材质与 Bloom 上严格分离。
- 敌军统一为深紫甲壳、血红结构与少量酸性眼核，七种船体和五类模块不复用人类构造器；模块改写表面脉络、尾器官、口器、甲壳缝和眼阵，敌弹采用生物倒刺语法。三章 Boss 分别重做为六瓣放射母巢、纵向熔炉脊柱/肩塔和中央裂隙双镰冠，并使用中性画廊证明本体差异。
- 体素最小边长提升到 0.12 世界单位并按 0.04 量化；每块实体都有自发光下限和 3.8% Glow 壳。新增五级 Unreal Bloom、显示白以上 HDR 选择阈值与 SMAA，只有能量器官产生紧凑辉光，白色装甲和环境保持清晰。
- 玩家普通弹改为低亮玩家色短矢，不再以白芯连成两条灯珠轨道；相位、追踪和重弹保留白芯，敌弹继续使用高饱和珊瑚/紫色倒刺。

完整美术规则见[3D 像素视觉方向](./VISUAL-DIRECTION.md)。
