# `docs/` 维护规则

本目录继承根级 [AGENTS.md](../AGENTS.md)。文档是可验证的工程资产，不是宣传性猜测。

- [文档中心](./README.md)维护导航与事实优先级；新增、移动、归档文档时同步更新。
- [当前项目状态](./PROJECT-STATE.md)只记录当前发行基线、开发快照、验证证据与缺口；历史细节留在 release 文档和 `CHANGELOG.md`。
- 玩法/系统变更更新 `CHANGELOG.md`、`DEVELOPMENT.md` 和状态快照；架构边界变更更新 `ARCHITECTURE.md`。
- 版本发布新增 `RELEASE-x.y.z.md`，同步 package/界面版本、打包记录、哈希和状态快照。未重新构建的旧产物不得标成新版本。
- 命令、路径、参数、数量和校验值必须来自仓库或实际执行结果。未运行的检查明确写“未验证”。
- 仓库内链接使用相对路径，外部技术结论优先链接官方文档。完成后运行 `npm run verify`。
